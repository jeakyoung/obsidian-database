## 📖 상세 내용

- 엔진은 톰캣의 가장 상위 레벨 컨테이너입니다.
- 하나 이상의 호스트(Host)를 포함하며, 각 호스트에는 하나 이상의 웹 애플리케이션을 배치할 수 있습니다.
- 엔진은 가상 호스팅(Virtual Hosting)을 지원하고, 다중 도메인 또는 IP 주소에 대한 다중 웹 사이트를 구성할 수 있습니다.
