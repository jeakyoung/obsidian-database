# 코딩테스트 기본 개념 문제

## 📋 개요

| 항목 | 내용 |
|:--|:--|
| **분류** | 면접준비 |
| **관련 기술** | Java, 자료구조, SQL, 웹 기초 |

> 코딩 구현형이 아니라 CS 기본 지식/개념을 묻는 형태의 코딩테스트 대비 Q&A. 신입 + 제조업 유지보수 부서 면접에서 나올 법한 수준으로 정리.

## 🧩 핵심 개념

- 알고리즘 구현보다 **CS 기본 개념을 설명할 수 있는지**를 묻는 형태로 나올 가능성이 더 높음
- Java/OOP, 자료구조 기초, DB 기초, 웹/네트워크 기초 네 영역으로 분류

## 📖 상세 내용

### Java / OOP

**Q1. 객체지향의 4대 특성은?**
> 캡슐화(데이터+기능을 하나로 묶고 숨김), 상속(부모 클래스 재사용), 다형성(같은 메서드가 다르게 동작), 추상화(공통 특징만 뽑아 설계)

**Q2. `==`와 `.equals()`의 차이는?**
> `==`는 객체의 주소(참조)를 비교, `.equals()`는 객체의 내용(값)을 비교. String 비교할 때 `==` 쓰면 안 되는 이유

**Q3. 배열(Array)과 리스트(ArrayList)의 차이는?**
> 배열은 크기가 고정, 리스트는 동적으로 크기 조절 가능. 리스트가 내부적으로 배열을 쓰지만 자동으로 늘려줌

### 자료구조 기초

**Q4. 스택(Stack)과 큐(Queue)의 차이는?**
> 스택은 LIFO(마지막에 넣은 게 먼저 나감, 뒤로가기 기능), 큐는 FIFO(먼저 넣은 게 먼저 나감, 대기열)

**Q5. 시간복잡도 O(n)과 O(n²)의 차이는?**
> O(n)은 데이터가 2배 늘면 처리 시간도 2배, O(n²)은 데이터가 2배 늘면 처리 시간이 4배로 늘어남 (반복문 안에 반복문이 있으면 보통 O(n²))

### DB 기초

**Q6. Primary Key와 Foreign Key의 차이는?**
> PK는 테이블 안에서 각 행을 유일하게 식별하는 키, FK는 다른 테이블의 PK를 참조해 테이블 간 관계를 맺는 키

**Q7. 트랜잭션의 ACID란?**
> 원자성(Atomicity, 전부 성공 또는 전부 실패), 일관성(Consistency, 데이터 규칙 유지), 격리성(Isolation, 동시 실행 시 서로 영향 안 줌), 지속성(Durability, 커밋되면 영구 저장)

**Q8. 인덱스를 쓰면 왜 조회가 빨라지나?**
> 테이블 전체를 순차 탐색하지 않고 정렬된 구조(보통 B-Tree)로 바로 찾아갈 수 있어서. 단, 쓰기(INSERT/UPDATE)는 인덱스도 같이 갱신해야 해서 느려질 수 있음

### 웹/네트워크 기초

**Q9. GET과 POST 방식의 차이는?**
> GET은 데이터 조회용, URL에 파라미터 노출(캐싱/길이 제한 있음). POST는 데이터 생성/변경용, body에 데이터 담아 전송(보안상 더 적합)

**Q10. REST API란?**
> HTTP 메서드(GET/POST/PUT/DELETE)로 자원(Resource)을 주소(URL) 기준으로 조작하는 설계 방식. 예: `GET /users/1`은 1번 유저 조회

## 💡 정리 및 활용

- 신입 + 제조업 유지보수 부서 조합이면 어려운 알고리즘(DP, 그래프)보다 위 수준의 CS 기본 개념 확인이 더 현실적인 범위
- 모르는 질문이 나오면 외운 답을 말하기보다, 아는 범위까지 설명하고 "이 부분은 추가로 찾아보겠다"는 식으로 마무리하는 게 솔직하고 좋은 인상을 줌
