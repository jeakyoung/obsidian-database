# 문자열 팰린드롬 판별

## 📋 개요

| 항목 | 내용 |
|:--|:--|
| **분류** | 코딩테스트 |
| **관련 기술** | Java, 문자열/배열 |
| **정리일** | 2026-10-13 |

> 주어진 문자열이 앞뒤로 읽어도 같은 팰린드롬인지 판별하는 기초 문제. 면접 코딩테스트 대비용.

## 🧩 핵심 개념

- 팰린드롬(palindrome): 앞에서 읽어도 뒤에서 읽어도 같은 문자열 (예: `level`, `racecar`)
- 접근 방법 두 가지
  - 문자열을 뒤집어서 원본과 비교
  - 투 포인터(양쪽 끝에서 하나씩 좁혀오며 비교)

## 📖 상세 내용

### 문제

주어진 문자열이 팰린드롬인지 판별하는 함수를 작성한다.

```java
public static boolean isPalindrome(String s) {
    // 구현
}
```

### 방법 A — 문자열 뒤집어서 비교

```java
public static boolean isPalindrome(String s) {
    String reversed = new StringBuilder(s).reverse().toString();
    return s.equals(reversed);
}
```

- `StringBuilder(s).reverse()`로 문자 순서를 뒤집은 뒤 원본과 `.equals()`로 비교
- 팰린드롬의 정의("뒤집어도 같다")를 그대로 코드로 옮긴 방식, 구현이 짧고 직관적

### 방법 B — 투 포인터

```java
public static boolean isPalindrome(String s) {
    int left = 0;
    int right = s.length() - 1;

    while (left < right) {
        if (s.charAt(left) != s.charAt(right)) {
            return false;
        }
        left++;
        right--;
    }
    return true;
}
```

- `left`는 앞에서, `right`는 뒤에서 시작해 서로 다가가며 문자를 비교
- 한 글자라도 다르면 즉시 `false` 반환, 끝까지 같으면 `true`
- 추가 문자열 생성이 없어 방법 A보다 메모리 효율적 (알고리즘 중심 풀이로 어필 가능)

## 💡 정리 및 활용

- 면접 코딩테스트에서는 방법 A처럼 라이브러리를 활용한 짧은 풀이도 충분히 좋은 답변
- 막히더라도 "팰린드롬 = 앞뒤 대칭"이라는 정의를 말로 풀어 설명하면서 접근하는 과정 자체가 중요
- 동일 패턴(투 포인터)을 배열 비교, 정렬된 배열 탐색 등에도 응용 가능
