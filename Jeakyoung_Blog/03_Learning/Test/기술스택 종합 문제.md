## 📖 상세 내용

### 1. Java — 오버로딩 vs 오버라이딩

Q. 메서드 오버로딩(Overloading)과 오버라이딩(Overriding)의 차이는?

A. 오버로딩은 같은 클래스 안에서 이름은 같고 매개변수(타입/개수)가 다른 메서드를 여러 개 정의하는 것. 오버라이딩은 부모-자식 상속 관계에서 부모의 메서드를 자식이 같은 시그니처로 재정의하는 것.

### 2. JSP — JSP와 서블릿의 관계

Q. JSP는 실행될 때 내부적으로 어떻게 동작하나요?

A. JSP 파일은 최초 요청 시 서블릿(.java)으로 변환·컴파일되어 실행된다. JSP는 "HTML처럼 쓰기 편하게 만든 서블릿"이라고 볼 수 있다.

### 3. JavaScript — var / let / const

Q. `var`, `let`, `const`의 차이는?

A. `var`는 함수 스코프 + 재선언/재할당 가능(호이스팅 이슈 있음). `let`은 블록 스코프 + 재할당만 가능. `const`는 블록 스코프 + 재할당 불가(단 객체 내부 속성 변경은 가능).

### 4. JavaScript — 비동기 처리

Q. `Promise`와 `async/await`의 관계를 설명해보세요.

A. `Promise`는 비동기 작업의 결과(성공/실패)를 나중에 처리할 수 있게 감싸는 객체. `async/await`는 Promise를 동기 코드처럼 보이게 작성할 수 있게 해주는 문법(내부적으로는 여전히 Promise 기반).

### 5. Vue.js — computed vs methods

Q. Vue에서 `computed`와 `methods`의 차이는?

A. `computed`는 의존하는 데이터가 바뀔 때만 재계산되고 캐싱됨(값처럼 취급). `methods`는 호출될 때마다 매번 새로 실행됨. 화면에 여러 번 쓰이는 계산값은 `computed`가 효율적.

### 6. React — JSX와 상태(state)

Q. React의 `useState`는 왜 필요한가요?

A. React 컴포넌트는 함수가 다시 실행돼야 화면이 갱신되는데, 일반 변수는 값이 바뀌어도 리렌더링을 못 일으킨다. `useState`로 관리하는 값은 바뀌면 컴포넌트를 자동으로 재렌더링시켜준다. (Vue의 `data`와 같은 포지션)

### 7. Oracle — 특유 문법

Q. Oracle에서 `ROWNUM`과 `NVL`은 각각 무엇인가요? MS SQL이면 뭐로 대체하나요?

A. `ROWNUM`은 조회 결과에 순번을 매기는 가상 컬럼(상위 N개 조회 시 사용) → MS SQL에서는 `TOP N`. `NVL(값, 대체값)`은 NULL이면 대체값을 반환 → MS SQL에서는 `ISNULL(값, 대체값)`.

### 8. MS SQL — IDENTITY

Q. MS SQL의 `IDENTITY` 컬럼이란?

A. INSERT 시 값을 지정하지 않아도 자동으로 1씩 증가하는 값을 넣어주는 컬럼 속성 (Oracle의 `SEQUENCE`와 비슷한 역할, Oracle은 시퀀스를 별도 객체로 만들어 `.NEXTVAL`로 가져와야 함).

### 9. SQL 종합 — 계층형 데이터 조회 (PLM/BOM 연관)

Q. 부품(PART_ID, PARENT_PART_ID) 테이블처럼 상위-하위 부품 구조(트리)를 한 번에 조회하려면 어떻게 하나요?

A. MS SQL/PostgreSQL 등은 재귀 CTE(`WITH ... AS`에 자기 자신을 참조)를 사용. Oracle은 `CONNECT BY PRIOR` 문법을 사용. BOM처럼 부품 트리를 다루는 PLM 도메인에서 실제로 자주 쓰이는 패턴.

```sql
-- MS SQL 재귀 CTE 예시
WITH PartTree AS (
    SELECT PART_ID, PARENT_PART_ID, 0 AS LEVEL
    FROM PART WHERE PARENT_PART_ID IS NULL
    UNION ALL
    SELECT P.PART_ID, P.PARENT_PART_ID, PT.LEVEL + 1
    FROM PART P
    JOIN PartTree PT ON P.PARENT_PART_ID = PT.PART_ID
)
SELECT * FROM PartTree;
```

### 10. 종합 실무형 — 배열 중복 제거

Q. 문자열 배열에서 중복을 제거하고 반환하는 함수를 작성하세요.

```java
public static List<String> removeDuplicates(String[] arr) {
    Set<String> set = new LinkedHashSet<>(Arrays.asList(arr));
    return new ArrayList<>(set);
}
```

`LinkedHashSet`을 쓰면 중복 제거 + 원래 순서 유지가 둘 다 가능 (단순 `HashSet`은 순서 보장 안 함).

## 💡 정리 및 활용

- 9번(BOM/트리 조회)이 PLM 직무 특성상 가장 실무와 가까운 문제 — 재귀 CTE/CONNECT BY 개념만 입으로 설명할 수 있으면 충분
- Oracle/MS SQL 문법 차이(7, 8번)는 "같은 개념, 다른 문법"이라는 틀로 기억하면 헷갈리지 않음
