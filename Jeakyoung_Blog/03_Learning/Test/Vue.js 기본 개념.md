# Vue.js 기본 개념

> Vue.js는 데이터와 화면을 자동으로 동기화시켜주는 프론트엔드 프레임워크. 면접에서 개념 설명 가능한 수준으로 정리.

## 🧩 핵심 개념

- Vue.js는 화면(UI)을 데이터와 자동으로 동기화시키는 **반응성(reactivity)** 기반 프론트엔드 프레임워크
- React, Angular와 같은 포지션의 라이벌 프레임워크
- 화면을 재사용 가능한 조각인 **컴포넌트** 단위로 나눠 조립하는 방식

## 📖 상세 내용

### 왜 필요한가 (문제 상황)

옛날 방식(JSP, 순수 JS)은 데이터가 바뀔 때마다 화면의 어느 부분을 다시 그릴지 **수동으로 DOM을 조작**해야 했다.

```javascript
document.getElementById("count").innerText = count; // 수동으로 화면 갱신
```

Vue는 데이터(`count`)를 바꾸면 화면이 자동으로 따라 바뀌게 해서 이 수동 작업을 없애준다.

### 핵심 개념 3가지

**1. 데이터 바인딩**

```html
<div id="app">{{ count }}</div>
```

```javascript
const app = Vue.createApp({
  data() { return { count: 0 } }
}).mount('#app');
```

`count` 값이 바뀌면 화면의 `{{ count }}` 부분이 자동 갱신된다.

**2. 컴포넌트**

화면을 레고 블록처럼 재사용 가능한 조각(컴포넌트)으로 나눠서 조립한다. 예: 버튼, 카드, 리스트 아이템을 각각 컴포넌트로 만들어 재사용.

**3. 이벤트 처리**

```html
<button @click="count++">증가</button>
```

클릭 같은 사용자 동작에 맞춰 데이터를 바꾸면, 화면은 또 자동으로 갱신된다.

### React와 비교

| | Vue.js | React |
|:--|:--|:--|
| 문법 | HTML에 가까운 템플릿 | JSX(JS 안에 HTML을 섞어 씀) |
| 학습 곡선 | 비교적 쉬움 | 상대적으로 어려움 |
| 만든 곳 | 개인 개발자(Evan You) | Meta(Facebook) |
| 공통점 | 둘 다 "데이터가 바뀌면 화면이 자동으로 바뀐다"는 철학 공유 |

## 💡 정리 및 활용

면접에서 이렇게 답하면 된다:

> "Vue.js는 데이터와 화면을 자동으로 동기화시켜주는 프론트엔드 프레임워크로, 화면을 컴포넌트 단위로 쪼개서 개발하는 방식입니다. 직접 실무로 다뤄본 경험은 많지 않지만, 백엔드에서 API를 설계할 때도 프론트가 데이터를 어떻게 받아서 화면에 반영하는지 고려해왔기 때문에 개념적으로는 익숙하고, 실제 문법도 React보다 진입장벽이 낮아 빠르게 적응할 수 있다고 생각합니다."

신입 면접에서 Vue 심화 질문까지 나올 가능성은 낮으므로, 개념 수준 설명이면 충분하다.
