# ENOVIA PLM 개념 정리

## 📋 개요

| 항목 | 내용 |
|:--|:--|
| **분류** | 면접준비 |
| **관련 기술** | PLM, ENOVIA, 다쏘시스템 |
| **정리일** | 2026-10-13 |

> PLM 개념과 다쏘시스템의 ENOVIA 솔루션, 제조업에서의 역할을 면접 답변 가능한 수준으로 정리.

## 🧩 핵심 개념

- **PLM(Product Lifecycle Management)**: 제품 기획~설계~생산~서비스~폐기까지 전체 라이프사이클 데이터를 통합 관리하는 것. 설계/생산/품질/구매 부서가 같은 제품 데이터를 공유하게 하는 게 목적
- **ENOVIA**: 다쏘시스템(Dassault Systèmes)의 PLM 솔루션. 전신은 MatrixOne, 이후 3DEXPERIENCE 플랫폼의 한 모듈로 통합
- 제조업에서는 설계 변경 하나가 생산/재고/품질/구매에 영향을 주기 때문에, "누가 언제 뭘 왜 바꿨는지" 추적 가능하게 만드는 것이 본질

## 📖 상세 내용

### 핵심 기능

| 기능              | 설명                                                             |
| :-------------- | :------------------------------------------------------------- |
| BOM 관리          | Bill of Materials — 제품을 구성하는 부품 목록을 계층 구조(상위 부품-하위 부품)로 관리     |
| 변경관리 (ECR/ECO)  | Engineering Change Request/Order — 설계 변경 시 이유·영향 범위를 승인 절차로 추적 |
| 버전/문서관리 (Vault) | 설계 문서/CAD 파일을 체크인(저장)/체크아웃(수정 중 잠금)하며 버전 관리                    |
| 워크플로우/협업        | 설계 → 검토 → 승인 단계를 전자적으로 거치는 결재 프로세스                             |
| CAD 연동          | CATIA, SOLIDWORKS 등에서 만든 3D 설계 파일을 ENOVIA Vault에서 관리           |

### 기술적 커스터마이징 구조 (신입이 투입되는 영역)

- **MQL(Matrix Query Language)**: ENOVIA 내부 데이터를 조회/조작하는 전용 쿼리 언어 (SQL과 유사한 포지션)
- **TCL 스크립트**: 비즈니스 로직 자동화용 스크립트 언어
- **JPO(Java Program Object)**: Java로 작성하는 커스텀 비즈니스 로직 모듈
- **JSP 기반 UI(Common/Central 프레임워크)**: 전통적인 ENOVIA 화면은 JSP 구성, 최신 커스터마이징에서는 Vue/React를 추가로 얹는 구조도 가능

## 💡 정리 및 활용

면접 답변 예시:

> "ENOVIA는 다쏘시스템의 PLM 솔루션으로, 제품 설계부터 생산까지 전체 데이터를 관리하고 특히 설계 변경 시 ECR/ECO 같은 변경관리 프로세스를 통해 영향 범위를 추적하는 역할을 한다고 이해하고 있습니다. 직접 다뤄본 적은 없지만, 제가 해온 데이터 버전/이력 관리, 멀티테넌트 데이터 분리 작업과 개념적으로 닿아있는 부분이 많아서 실무로 빠르게 배울 수 있다고 생각합니다."
