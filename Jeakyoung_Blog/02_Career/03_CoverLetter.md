# 자기소개서 - 안재경

## 📋 개요

| 항목 | 내용 |
|:--|:--|
| **작성일** | 2026-09-21 |
| **소속·역할** | F1soft 솔루션사업팀 · ERP/MES 백엔드, 모바일 백엔드 API |
| **주요 기술** | Java, Sencha Ext JS, C# .NET Core, MSSQL, MariaDB |

## 🧭 경력 요약

평택대학교 정보통신학과를 졸업하고 2025년 7월부터 F1soft에서 ERP·MES 백엔드와 모바일 백엔드 API 개발을 맡고 있습니다.

## 🛠 주요 수행 내용

### 프레임워크 없이 시작한 실무

실무에 처음 투입됐을 때는 Spring이나 JPA 같은 프레임워크를 제대로 써본 적이 없었습니다. 정작 맡은 시스템들은 순수 서블릿과 JDBC로 저장 프로시저를 직접 호출하는 구조였고, 처음엔 당황스러웠습니다. 그런데 오히려 그 덕분에 "프레임워크가 대신 처리해 주는 부분"을 건너뛰지 않고, 요청 하나가 실제로 어떤 SQL까지 이어지는지를 눈으로 따라가며 배울 수 있었습니다. IPACK 근태 시스템의 시간 계산 로직(지각·조퇴는 올림, 초과근무는 내림, 표준 근무시간은 반올림)을 정리하면서, 겉보기엔 단순한 계산도 규칙을 하나만 놓치면 실제 급여·근태 기록이 조금씩 어긋난다는 걸 몸으로 확인했습니다.

### 언어를 오가며 설계로 넘어가기

같은 시기에 C# .NET Core로 I-Frog 모바일 백엔드를 맡으면서, 업체마다 따로 커스터마이징해 붙여 쓰던 서버들을 하나의 백엔드로 합치는 작업을 진행했습니다. 요청 헤더의 보안 코드로 회사와 DB 환경을 구분해 연결 정보를 골라주는 구조를 설계하면서, Java와 C#을 오갈 때 정작 걸리는 건 문법이 아니라 "이 구조를 어떻게 설계할 것인가"라는 판단이라는 걸 체감했습니다. 이후 신규사업인 데이터 바우처 프로젝트에서는 이 I-Frog 코드베이스를 그대로 가져다 입고 라벨 이미지 수집 파이프라인을 새로 구성하면서, 한 번 설계한 구조를 다른 문제에 재적용하는 경험도 쌓았습니다.

### 두 시스템이 어긋날 때

신진SM ERP/MES는 저장이 끝나면 별도 커넥션으로 더존 ERP의 프로시저를 호출해 데이터를 반영합니다. 문제는 이 두 저장이 하나의 트랜잭션이 아니라는 것입니다. MES는 저장됐는데 더존 반영만 실패하는 경우가 사용자에게 드러나지 않았고, 포장 중복·재고 집계 불일치처럼 서로 다른 이름의 문제가 사실은 같은 구조에서 반복적으로 나오고 있다는 걸 확인했습니다. `@ISEXISTS_OUT` 같은 개별 가드를 하나씩 추가하며 대응해왔고, 아직 두 시스템의 커밋을 근본적으로 하나로 묶어서 해결하지는 못했습니다. 지금도 계속 붙잡고 있는 문제입니다.

### 혼자 처음부터 끝까지 만들어보기

회사 업무와는 별개로, 여행 콘텐츠 링크를 던지면 장소 정보를 자동으로 뽑아주는 서비스(ReeL-Trip)를 개인적으로 만들고 있습니다. 백엔드를 NestJS로 시작했다가 CORS·배포 이슈를 겪으면서 Spring Boot로 갈아엎었고, 유튜브·인스타그램처럼 플랫폼마다 콘텐츠 접근 방식이 완전히 다른 문제를 전략 패턴으로 풀었습니다. 테스트 코드가 아직 없다는 것도 알고 있고, 다음 과제로 남겨두고 있습니다. 이 프로젝트를 통해 "설계를 바꿀지 말지"를 스스로 판단하고 끝까지 책임지는 경험을 해볼 수 있었습니다.

### 핵심 강점

레거시 코드에서 실제 동작을 정확히 추적하는 데 익숙하고, 두 시스템이 비동기로 얽힐 때 생기는 문제의 근본 원인을 끝까지 따라가려는 편입니다. 문서를 남길 때는 아는 것과 모르는 것을 분명히 구분하는 걸 원칙으로 하고 있습니다.

### 앞으로 하고 싶은 것

지금까지는 이미 있는 시스템을 유지보수하고 고치는 일이 많았다면, 앞으로는 처음부터 설계하는 경험을 더 쌓고 싶습니다. 특히 여러 시스템이 얽혀서 데이터 정합성이 깨지는 문제(신진SM에서 계속 마주하고 있는 문제)를 구조적으로 해결하는 백엔드 개발자로 성장하고 싶습니다.

## 🏆 성과 및 역량

지금까지의 경험을 한 문장으로 정리하면, "프레임워크 없이 시작했지만 구조를 직접 설계하는 방향으로 나아가고 있는 개발자"입니다. ERP·MES의 레거시 코드베이스와 개인 프로젝트의 신규 설계를 병행하며 두 관점을 모두 쌓고 있습니다.
