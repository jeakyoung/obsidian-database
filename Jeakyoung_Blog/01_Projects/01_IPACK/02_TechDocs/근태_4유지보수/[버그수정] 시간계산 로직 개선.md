## 🎯 배경 및 요구사항

근무조별 일근태등록(WHR314)에서 시간 계산의 정확성을 높이기 위해 구현한 시간 변환 함수와 종합 계산 로직. 최종 수정 2025-12-30.

## 🏗 설계 및 구현

### 시간 계산의 반올림 규칙

| 항목 | 처리 | 적용 대상 |
|:--|:--|:--|
| 지각/조퇴 (Minus Hour) | 올림(ceil) 쪽으로 유리하지 않게 처리 | `LATE_TIME`, `EARLY_TIME` |
| 초과근무 (Plus Hour) | 내림(floor) 쪽으로 유리하게 처리 | `OVER_TIME`, 특근 관련 |
| 표준 시간 (Decimal Hour) | 반올림(round) | `BASIC_TIME` |

### 시간 변환 함수 (실제 소스, `WHR314_CT.js` 188~291행)

> [!note]
> 아래 코드는 `iPlusERP/WebContent/app/controller/HR/WHR300/WHR314_CT.js`를 그대로 옮긴 것이다. 이전 버전 문서에는 "분 단위를 먼저 `Math.ceil`/`Math.floor`로 계산한다"고 적혀 있었지만, 실제 코드는 **HHMM 4자리 입력 경로에서 분을 먼저 `Math.round`로 정규화한 다음** 10분 단위로 ceil/floor/round를 적용한다 — 미세하지만 실제 반올림 결과에 영향을 줄 수 있는 차이라 코드 기준으로 정정했다.

#### convertToMinusHour (지각/조퇴)

```javascript
convertToMinusHour: function (rawTime) {
    if (rawTime === null || rawTime === undefined || rawTime === '') return NaN;
    if (String(rawTime).indexOf(':') >= 0) {
        var parts = String(rawTime).split(':');
        if (parts.length >= 2) {
            var h = parseInt(parts[0], 10) || 0;
            var m = parseInt(parts[1], 10) || 0;
            var total = h + (Math.ceil(m / 10) * 10) / 60;
            return Number(total.toFixed(2));
        }
    }
    var s = String(rawTime).replace(':', '');
    if (s.length === 3) s = '0' + s;
    if (!/^\d+$/.test(s)) return NaN;
    var num = parseFloat(s) / 100.0;
    var hours = Math.floor(num);
    var minutes = Math.round((num - hours) * 100); // HHMM 입력의 분을 우선 정규화
    minutes = Math.ceil(minutes / 10) * 10;         // 10분 단위로 올림 (지각/조퇴는 불리하게)
    if (minutes === 60) {
        hours += 1;
        minutes = 0;
    }
    return Number((hours + minutes / 60).toFixed(2));
}
```

`HH:MM` 형식 입력은 분을 바로 `Math.ceil`로 10분 단위 올림하고, `HHMM` 4자리 숫자 입력은 `Math.round`로 한 번 정규화한 뒤 다시 10분 단위로 올림한다 — 두 입력 경로의 중간 처리가 다르다.

#### convertToPlusHour (초과근무)

```javascript
convertToPlusHour: function (rawTime) {
    // ... HH:MM 경로는 Math.floor(m / 10) * 10
    var minutes = Math.round((num - hours) * 100); // HHMM 입력의 분을 우선 정규화
    minutes = Math.floor(minutes / 10) * 10;         // 10분 단위로 내림
    // ...
}
```

`convertToMinusHour`와 구조는 동일하고, 10분 단위 처리에서 `ceil` 대신 `floor`를 쓴다.

#### convertToDecimalHour (표준 시간)

```javascript
convertToDecimalHour: function (rawTime) {
    // HH:MM 경로: Math.round(m / 10) * 10
    var minutes = Math.round((num - hours) * 100);
    minutes = Math.round(minutes / 10) * 10;         // 10분 단위로 반올림
    // ...
}
```

#### convertToNightHour (야간근무)

```javascript
convertToNightHour: function (rawTime) {
    if (rawTime === null || rawTime === undefined || rawTime === '') return NaN;
    var s = String(rawTime).replace(':', '');
    if (s.length === 3) s = '0' + s;
    var num = parseFloat(s) / 100.0;
    var hours = Math.floor(num);
    var minutes = Math.round((num - hours) * 100);
    minutes = Math.floor(minutes / 10) * 10;
    if (minutes === 60) {
        hours += 1;
        minutes = 0;
    }
    return Number((hours + 24.0 + minutes / 60).toFixed(2));
}
```

야간근무는 24시간 기준으로 오프셋을 더해 다음날 시각과 직접 비교 가능하게 만든다. 예: `convertToNightHour("2200")` → `46.0` (22 + 24.0). 실제 코드에는 조퇴/지각의 야간 버전인 `convertToMinusNHour`(278행)도 별도로 존재하는데, 이전 버전 문서에는 없었다.

### 야간근무 계산 예시

```
22:00 ~ 06:00(다음날) = 8시간 근무
convertToNightHour("2200") = 22 + 24.0 = 46.0
다음날 06:00은 별도 로직에서 30.0(=6+24.0)로 계산되어 46.0과 비교 가능
```
