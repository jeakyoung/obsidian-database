## 🔍 현상 및 원인

주차정보 없이 등록 시 `WG_FROM_DATE`가 null로 전달되어, IUD 프로시저에서 "문자열을 날짜로 변경하지 못했습니다" 오류 발생.

## 🔧 조치 내용

---

### 요청사항

![[image 148.png]]

다음 사진과 같이 주차정보 없이 등록하고자 하면 주차정보가 IUD에 null값으로 전달되기에 프로시저 단에서

 null 값을 convert하지 못하고 “문자열을 날짜로 변경하지 못했습니다.” 오류가 발생합니다.

---

```javascript
onSetCombo_05: function () {
        var me = this;

        var store = this.getViewModel().getStore('storeCombo_05');
        store.load({
            params: {
                FACTORY_CODE: gFactoryCode,
                YYYYMM: Ext.util.Format.date(me.getView().down('#WHR316_VW_yymm').getValue(), 'Ym'),
            },
            callback: function (records, operation, success) {
                if (success) {
                    me.getView().down('#combo_05').setValue(records[0].get('WG_FROM_DATE'));
                }
            },
        });
    },
```

다음과 같이 조회조건은 근무주차로 이루어지기에 근무주차 콤보가 callback함수를 불러오는데 성공한 경우

combo_05내 선택된 근태 년월 값에 해당하는 가장 첫번째 값 ( 그 달의 1주차) 를 자동 호출하여

주차정보가 없어 FROM_DATE가 null값으로 들어가는 경우의 수를 제거했습니다.

## ✅ 검증 및 결과

- [x] `onSetCombo_05`가 `WHR316_CT.js`(142~167행)에 존재. 다만 현재 버전은 이 문서의 `records[0]` 단순 선택 방식보다 더 발전한 형태로, `IS_TODAY_WEEK == '1'`인 레코드를 우선 찾고 없으면 `records[0]`으로 폴백함 — 이후 추가 개선이 있었던 것으로 보이나 그 변경을 다룬 문서는 이 폴더 안에서 찾지 못함(미확인).
- [x] `onComboChange`의 `combo_05` 케이스가 `me.onView()`를 호출하는 부분은 이 문서 코드와 동일하게 남아있음.
