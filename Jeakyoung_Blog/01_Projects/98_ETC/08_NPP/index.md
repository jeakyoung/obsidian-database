# 뉴파워 프라즈마 (NPP)

정부지원사업 기반 신규사업. AI 관제 서비스·LLM 대시보드·챗봇 서비스 구축과 폴리싱 공정 작업 자동화가 목표이며, 2026-09 기준 요구사항 협의와 서버(Linux, RAID 1/5 구성, AVR 도입) 검수 단계를 진행 중이다. 개발 방법론(바이브코딩)에 대한 내부 검토도 병행하고 있다. 기술 스택은 요구사항 확정 전이라 아직 미확정 상태.

## 개요

| 항목 | 내용 |
|:--|:--|
| **담당 업무** | MLOps 개발 (신규사업) |
| **기술 스택** | 미확정 |
| **주요 서비스** | AI 관제 서비스, LLM 대시보드, 챗봇 서비스 |
| **공정 자동화** | 폴리싱 공정 작업 자동화 |
| **인프라** | Linux 서버, RAID 1 (시스템) / RAID 5 (데이터), AVR |
| **데드라인** | 2026년 12월말 |
