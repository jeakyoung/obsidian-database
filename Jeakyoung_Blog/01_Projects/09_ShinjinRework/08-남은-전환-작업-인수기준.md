## ⚙️ 환경 및 전제

기존 01–06의 단말·세션·작업 조회·공통 상태 전이를 재사용한다. 07 LOT 투입·반납의 합성 검증은 완료했다. 008 단일 계획 통합의 범위와 남은 항목은 아래 진행 상태를 따른다.

## 📖 상세 내용

### 기존 패턴

레거시 메뉴에서 생산, 물류, 관리, 장비·출력이 각각 별도 화면으로 진입한다. 008과 포장은 계획행·LOT·공정 인계 상태로 연결된다. 출하는 포장 결과를 받고, 공장이송·재고이동·입고는 재고 키와 전표 참조 규칙을 공유한다.

### 008·포장 진행 상태

- **P1 포장·P2 도면가공 008** — 단일 계획의 1차 포장 → 008 → 2차 포장 → 합성 출하 인계가 통과했다. 생략 승인·거절, 2차 직접 완료 및 중복 방지를 확인했다.
- **생산그룹** — 후보 중복 제거, 공용 LOT 경합, 일부 실패 시 전체 보존, 공통 합성 일보·수불번호와 계획별 항번이 통과했다. 그룹·감사 조회에서 완료 후 계획별 배정을 확인했고, 실패한 시작은 배정을 추가하지 않으며 실패한 완료는 기존 배정을 보존했다. [도면가공 생산그룹과 공용 LOT](11-도면가공-생산그룹과-공용-LOT.md)
- **별도 미완** — 정상·생략 혼합 묶음 자동 배정, 실제 작업시간·실적·일보·수불·출하 헤더와 명세 대조 및 취소·보정이 남았다. P1·P2 전체 체크는 열린 상태로 둔다.
- **L1 출하** — 합성 인계 식별자 발생까지 확인했다. 출하 화면에서 실제 포장 결과를 받는 통합과 출력 연계는 후속이다.

- [도면가공 008과 포장·출하 인계](09-도면가공-008.md)

### 다음 인계와 병렬화

| 담당 | 병렬 착수 기준 | 통합 인수 기준 |
| --- | --- | --- |
| P2 생산 008 | C1의 계획행 키, LOT 참조, 1차 포장 인계 입력, 008 완료 응답을 합의한다. P1의 1차 인계 응답과 07 LOT 응답을 합성해 정상·확인 후 예외 진행·취소를 각각 검증한다. | P1의 실제 1차 결과로 008을 시작하고 동일 계획행의 2차 포장 대상으로 한 번만 인계한다. LOT 참조와 오류 응답을 대조한다. |
| P1 포장 | 같은 C1 계약으로 정상 포장과 1차 포장 산출을 개발하고, 합성 008 완료 응답으로 2차 포장 및 출하 인계까지 검증한다. | 1차 포장 → 008 → 2차 포장을 한 계획행으로 연결한다. 최종 포장 결과를 L1에 전달하고 재시도 후에도 인계가 한 건인지 확인한다. |
| L1 출하 | C2와 포장 인계 필드인 계획행·포장 식별자·품목·수량을 합의한다. 합성 포장 결과와 합성 출력 응답으로 출하·삭제·재출력을 검증한다. | P1의 실제 포장 결과로 출하를 확정하고 D3 출력 연결에서 같은 출하번호의 재출력이 출하를 중복 생성하지 않는지 확인한다. |
| L2–L5 이송·재고·입고 | C2 합의 후 업무별로 독립된 합성 문서와 초기 재고를 사용한다. 공장이송, 재고이동, ESCO 입고, 발주입고를 각각 착수한다. | 업무별 정상·거절·재시도 검증 후 공통 재고·전표 계약을 대조한다. 이체 경로는 ERP 단계만 반영된 실패 후 재시도까지 확인한다. |

P1과 P2는 서로의 구현 완료를 기다리지 않고 합성 인계로 개발한다. 통합 검증에서만 1차 포장 → 008 → 2차 포장 → 출하 순서를 따른다. L2–L5는 이 순서와 독립적으로 진행한다.

### 장비·문서 출력

- **D1** — 작업지시 스캔과 LOT 선택을 Chrome에서 확인했다. 조회·선택이 서버를 변경하지 않고, 명시적 LOT 투입의 오래된 revision은 409로 거절됐다.
- **D2** — 등록·매칭·적재·수동 이동·이력, 타 작업자의 기존 키와 새 이동 거절을 Chrome에서 확인했다. Java 하네스로 쓰기 직전 예외, 동시 재전송 및 타 단말 거절을 확인했다.
- **D3** — 합성 출력·PDF·미리보기는 별도 검토 중이다. D1·D2의 독립 통합 리뷰도 확정 대기이며, 실물 장비와 008 묶음 전체의 통합 회귀는 이번 실행에서 미검증이다.

### 검증

- [ ] 작업 단위별 화면·API 진입점, 합성 입력, 정상·거절·재시도 결과를 인수 기록에 남긴다.
- [ ] 생산·출하는 동일 계획행과 포장 참조로 최종 인계까지 추적한다. 물류는 업무별 원전표·항번과 수량 변화 및 중복 반영 여부를 확인한다.
- [ ] 구현이 연결되기 전에 합성 응답으로 검증한 항목과 연결 후 확인한 항목을 인수 기록에 표시한다.
