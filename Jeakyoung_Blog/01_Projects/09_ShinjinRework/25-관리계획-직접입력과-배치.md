# 관리계획 직접입력과 배치

## 📋 개요

[[21-생산계획-현황-역발행과-제품규격-변경]]의 후속이다. 게시 준비 기준은 main `221658b`, vault `b3d4533`이다. 최신 구현 인계는 `221658b` 기반이며 공용 App과 RFID 사진 파일은 기준과 동일하다.

## 📖 상세 내용

- **관리계획 직접입력**은 `COMMON/ComReversePlan1.cs`의 입력 검증과 기준 월 기록을 대조한다. Spring 데모는 제품 상태·치수·수량·창고 권한을 검증하고 별도 관리계획을 기록한다. 원 주문 발행량과 작업계획은 보존한다.
- **배치**는 역발행과 제품규격 변경을 종류별로 제출한다. `ComReversePlan1`과 `ComReversePrdStdChange2`의 처리 흐름을 기준으로 원 주문·계획·위치별 LOT 누적량을 임시 원장에서 검증한다. 성공 때만 전체 행을 반영하고 revision을 한 번 올린다. 중간 행 실패는 원장과 번호를 보존하고 동일 키 재생은 원 결과를 반환한다.
- **화면 수명**은 기존 생산계획 메뉴를 사용한다. 계획·재고이동의 cleanup에서 카운터 객체를 캡처하고 지연된 성공·401이 이전 화면에서 적용되지 않도록 기존 수명 검사를 유지한다.
