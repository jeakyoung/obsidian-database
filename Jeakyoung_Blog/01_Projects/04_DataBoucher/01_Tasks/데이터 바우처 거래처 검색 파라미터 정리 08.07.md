# 데이터 바우처 거래처 검색 파라미터 정리 08.07

## 📋 개요

| 항목 | 내용 |
|:--|:--|
| **요청자** | — |
| **요청일** | 2026-08-07 |
| **대상 시스템** | F1Soft.Starmap.Service — Search |
| **관련 화면·프로그램** | `SearchListController`, `SearchListService`, `SP_APP_CUSTOMER_LIST` |

> 거래처 검색 요청 모델에서 실제 쓰이지 않던 `CustomerCode`/`SearchItem` 필드를 제거하고 `CustKind`/`CustomerName` 두 개로 단순화.

## 🔍 현상 및 원인

### 재현 조건

거래처 목록 검색 시 오류가 발생/부정확한 결과가 나왔다.

### 원인

`CustomerListRequest`에 `CustomerCode`, `CustomerName`, `CustKind`, `SearchItem` 4개 필드가 있었지만, `SP_APP_CUSTOMER_LIST` 호출부에서 실제 검색 의도와 맞지 않는 파라미터(`CUSTOMER_CODE`, `SEARCH_ITEM`)까지 함께 넘기고 있어 검색 결과가 어긋났다.

## 🔧 조치 내용

| 구분 | 대상 | 변경 내용 |
|:--|:--|:--|
| 모델 | `Models/Search/CustomerListRequest.cs` | `CustomerCode`, `SearchItem` 필드 제거. `CustKind`, `CustomerName`만 유지 |
| SP 호출 | `Services/Search/SearchListService.cs` | `SP_APP_CUSTOMER_LIST` 파라미터를 `CUST_KIND`, `CUSTOMER_NAME` 두 개로 축소, 에러 로그의 `CustomerCode` 참조 제거 |
| 문서 | `Controllers/Search/SearchListController.cs` | XML 문서 주석의 샘플 요청 바디를 실제 필드에 맞게 수정 |
