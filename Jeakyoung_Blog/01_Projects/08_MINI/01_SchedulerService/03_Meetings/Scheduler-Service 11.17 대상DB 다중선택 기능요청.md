# Scheduler-Service 11.17 대상DB 다중선택 기능요청

## 📋 개요

| 항목 | 내용 |
|:--|:--|
| **일시** | 2026-11-17 |
| **장소** | (개인 작업, 세션) |
| **참석자** | 안재경 |
| **안건** | 반복주기 UI, 스케줄당 대상DB 다중선택, 업체별 모아보기 — 신규 기능 3가지 확정 |

## 💬 논의 내용

"스케줄 설정 시 크론 표현식 대신 년월일시분으로 받아 서비스가 크론으로 변환, 알람설정하듯 일별/월별/년별/특정시간대를 직관적으로 볼 수 있게 해달라"는 요청과, "대상DB설정으로 등록된 건들을 스케줄에 유동적으로 타겟팅할 수 있게, 업체별로 모아보기도 만들어달라"는 요청. "특정시간대"의 의미와 "업체별 모아보기"의 그룹핑 기준을 되물어 확정했고, "지금처럼 전체 스케줄을 대상DB 1개에 고정하는 게 아니라 여러 DB 커넥션을 동시에 호출할 수 있어야 한다"는 설명으로 범위가 명확해졌다.

## ✅ 결정 사항

| # | 결정 내용 | 근거 |
|:--|:--|:--|
| 1 | "특정시간대"는 요일반복/간격반복/1회성 특정일시 3가지 패턴 전부 지원 | 알람 설정처럼 직관적인 반복주기 표현이 목표 |
| 2 | "업체별 모아보기"는 target_db_config(이미 이름 보유)를 그룹 기준으로 재사용, 새 필드 신설 안 함 | 가장 단순한 방식 |
| 3 | 스케줄 1개가 대상DB 여러 개를 선택할 수 있게 1:1 FK → N:M 구조로 전환 | 한 업체 안에 여러 다운스트림 대상(지점별 DB 등)이 있는 경우를 지원 |
