### 재고 조정 화면 개선

- 창고 별 재고 현황 - 입출 테이블에 삭제되지 않은 데이터가 하나 남아있는 케이스 발견
- 재고 조정 화면에서 입출수량기준/반영재고기준 시인성 개선 필요
- 창고번호는 화면에서 히든 처리하기

### PART_NO 불일치 문제

- 신규 테스트 필요: 더존ERP와 MES 간 `PART_NO`가 다른 경우 탐색
- 제품마스터에 들어가야 할 품목이 자재마스터에 들어가 있는 경우가 있음
- 생산실적등록 시 `PART_NO` 통일 필요 — 도면가공 시 규격·PART_NO가 다름(다른 자재가 들어감)
- 저장품까지 전부 나오는 문제 — 플레이트만 보이도록 필터링 검토 필요
- MSL(창고이동) 관련 참고: `UP_PU_PTPGR_SELECT_H`, `UP_PU_PTPGR_SELECT_L`

### ERP 잔여(고아) 데이터 정리

- `MM_QTIO`, `MM_QTIOH`에서 `NO_IO = 'MPO20260700984'`가 조회되지 않는 케이스 발견
- 수불번호가 없는 건들은 MES에서 삭제 처리해도 ERP상에 잔여 데이터가 남음
- ERP상 수불번호가 MSL로 되어 있는 경우 삭제 방식: S/L 간 이동 처리 → 날짜·이동번호 추가해서 조회 → 맞는 건을 찾아서 바로 삭제
- 사라진 재고 찾는 법: 일별재고현황에서 창고번호를 기입하고 조회 (예: `11-20*340*2270J`, 07/20일자, `s20210701`)
- 생산입고건만 있는 경우 생산일보등록 화면에서 생산일보번호로 조회해서 삭제
