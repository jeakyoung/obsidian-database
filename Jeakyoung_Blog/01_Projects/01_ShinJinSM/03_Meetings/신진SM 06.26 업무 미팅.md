### 재고조정 개선 필요사항 — 사업장 코드 하드코딩

![[Pasted image 20260626110842.png|691]]

- 해당 부분 사업장이 `1000`번으로 고정되어 있음 — 더존에서 받아와서 사업장별로 매핑해줘야 함
- 똑같은 품목코드에 사업장만 다른 경우가 생기므로 `1000` 하드코딩 금지

**검증 쿼리:**

```sql
WITH MES_MAPPING AS (
    SELECT '000001' AS MES_PLANT_CODE, '2000' AS CD_PLANT_매핑값, '정남' AS MES_사업장명 UNION ALL
    SELECT '000002',                   '1000',                    '장수' UNION ALL
    SELECT '000003',                   '3000',                    '동탄' UNION ALL
    SELECT '000004',                   '4000',                    '직영' UNION ALL
    SELECT '000005',                   '5000',                    '천안' UNION ALL
    SELECT '000006',                   '6000',                    '남인천' UNION ALL
    SELECT '000007',                   '7000',                    '향남' UNION ALL
    SELECT '000008',                   '8000',                    '경기북부' UNION ALL
    SELECT '000009',                   '9000',                    '기획실' UNION ALL
    SELECT '000010',                   '9100',                    '대전' UNION ALL
    SELECT '000011',                   '9200',                    '서울' UNION ALL
    SELECT '000012',                   '9300',                    '정남직영'
)
SELECT
    m.MES_PLANT_CODE,
    m.CD_PLANT_매핑값,
    m.MES_사업장명,
    p.CD_PLANT      AS DZ_CD_PLANT,
    p.NM_PLANT      AS DZ_공장명,
    CASE WHEN p.CD_PLANT IS NULL THEN 'Error' ELSE 'Success' END AS 검증결과
FROM MES_MAPPING m
LEFT JOIN NEOE.MA_PLANT p
    ON p.CD_COMPANY = '1000'
    AND p.CD_PLANT  = m.CD_PLANT_매핑값
ORDER BY m.MES_PLANT_CODE
```

### 도면 가공 프로세스 설계

- 공정 이후 포장 시에 도면 가공으로 넘기기
- 포장 일반 → 출하로. 도면 가공을 추가해주고, 포장 후 출하 시에 출하가 한 줄 더 생김
- 기존 일반 프로세스: 수주 → 공정 완료 → 포장 → 출하
- 도면 가공 프로세스: 수주 → 공정 완료 → 포장(이력에 "도면"이라고 쌓기) → 도면 가공 → 포장 → 출하
- 기존 출하 리스트에서 같이 조회되므로 포장 데이터와 구분할 구분자 필요 (네이밍에 "포장" 사용하지 않기)

### 실적 등록 시 야간조 날짜 자동 계산

- 요구사항: 종료 시각이 24시~07시 30분 사이인 경우 전날 기준으로 날짜를 붙여줘야 함
- 조치는 완료했으나 테스트는 하지 않음
- 날짜 전처리 로직이 중복되어 있는 부분이 있고, 기존에 정상 처리가 어떻게 가능했는지는 파악 안 됨

## ✅ 결정 사항

- 재고조정 사업장 코드는 `1000` 등 하드코딩 금지, 더존 기준 매핑표로 대체하기로 함 (매핑 자체는 위 쿼리로 검증 완료)
- 도면 가공은 별도 이력 태그("도면")를 남기고 기존 포장/출하 리스트와 구분자로 분리하기로 함
