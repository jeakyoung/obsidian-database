## 💬 논의 내용

### 도면 가공 흐름

- 외주 받은 자재를 바로 투입하는 경우도 있고, 비규격 반은 길이 절단이 없음
- 입고에서 도면 가공을 찍으면 3400번 창고로, 완료 시에는 7000번으로 이동
- 포장을 하든 하지 않든 도면 가공에서 조회 가능해야 함 (포장을 찍고 도면 가공에서 조회)
- 결론: 일반 포장은 필수가 아님. 포장 = 생산 입고를 잡는 것. 완료 시 3400 창고에서 7000번으로 재고 이동
  1. 이전 실적 존재 시: 3400 창고로 생산 실적 생성
  2. 이전 실적 미존재 시: (추가 논의 필요, 결론 미정)
  3. 3400번 창고로 실적이 있는 경우 포장 → 출하 가능
- 도면 가공 창고를 만들고, 도면 가공 시에 창고 이동을 시킴(생산 포장). 완료 시 3400 창고로 창고 이동 생성
- 기본적으로 작업자들이 포장하면 안 되지만, 습관적으로 포장하는 경우를 고려해서 제작해야 함

### 정상 프로세스

측면/길이절단(3000) → 포장 완료(창고이동) → 도면시작(6000) → 도면완료(3400) → 포장(7000)

### 예외 사항

- 이전 공정이 아예 없는 경우 → 창고에서 -1(마이너스) 됨
- 도면 가공에 들어가야 하는데 습관적으로 포장을 한 경우
- 플레이트 포장 시 자동 스킵 처리 (스킵돼도 무방)
- 선행공정 실적이 없을 때: 마이너스 허용, 도면가공 시 규격 가져오기, 투입자재 없이도 시작 가능

> [!note] 설계 대비 실제 구현 변경
> 여기서 논의된 창고 체계(`3000/3400/6000/7000`)는 2026-09-14 실제 구현([[신진SM 도면가공 체계 MES 동기화 작업]])에서 `018`(도면가공창고)/`016`·`225`(출하창고), 더존 ETC `4200`/`7000` 체계로 바뀌었다. 설계가 굳어지기 전 여러 차례 창고 번호 체계 자체가 변경된 것으로 보인다.

## ✅ 결정 사항

- 일반 포장은 필수 단계가 아니며, 도면 가공 완료 시 3400 → 7000 창고 이동으로 처리하기로 함
