# 신진SM 포장 중복 조회 기능 요청 (에러리스트 페이지)

## 📋 개요

| 항목 | 내용 |
|:--|:--|
| **요청자** | 신진SM 현장 |
| **요청일** | 2026-09-01 |
| **대상 시스템** | MES(신규 화면) |
| **관련 화면·프로그램** | 미착수 — 신규 페이지 |

## 🔍 현상 및 원인

포장 중복 문제([[신진SM 중복 포장문제 ( 05.22 )]], [\[완료\] 포장중복문제 분석](<../02_TechDocs/[완료] 포장중복문제 분석.md>))가 발생해도 이를 사용자가 직접 조회할 방법이 없음 — 지금까지는 발생할 때마다 개발자가 로그/DB를 수동으로 확인해서 대응해왔다([[신진SM 개발 이력]]의 "관측 인프라가 거의 없다" 회고와 같은 맥락). 09-01 미팅에서 이 문제를 현장에서 직접 조회할 수 있는 화면이 필요하다는 요청이 나옴.

## 🔧 조치 내용 (요청 단계, 미착수)

09-01 회의록에 기록된 요구사항:

- MES상에서 포장 중복이 발생되어 있는 수주 건을 조회할 수 있는 신규 페이지("에러리스트") 필요
- 체크박스 등으로 건별 선택 가능한 형태로 요청됨
- 같은 미팅에서 함께 언급된 관련 요청: "실재고가 있는데 포장입고가 잡히는 경우 확인 필요" — 에러리스트 화면의 조회 대상에 포함될 가능성이 있는 케이스

구현 방향, 화면 설계, 대상 테이블/쿼리는 이 시점 기준 전혀 정해지지 않음 — [\[완료\] 포장중복문제 분석](<../02_TechDocs/[완료] 포장중복문제 분석.md>)에서 정리한 중복 발생 지점(WMA624/WPR559 두 경로)을 참고해 조회 대상 범위를 먼저 정의해야 함.

## ✅ 검증 및 결과

미착수. 요구사항 수집 단계.
