# 신진SM 09.08 내부 미팅

## 📋 개요

|:--|:--|
| **일시** | 2026-09-08 |
| **장소** | — |

## 💬 논의 내용

- 수주포장수: 포장을 더 많이 한 경우(중복)에 대해 조회 가능하도록 — 이상건은 컬럼에 핑크색 처리
- 출하수량 표기 추가
- 이월건 표기 추가
- 도면가공건 표기 — 도면가공 여부를 구분 표시. 흐름: 규격 → 포장 1차 → 도면가공 → 포장 2차 → 출하

**판별 기준 코드:**
- `008` (WORK_CODE) → 도면가공 여부 확인 가능
- `TPR601` → 1차 포장 여부 확인 가능
- `ITEM_KIND2` → 값이 `A70`이면 전부 도면가공 품목

## ✅ 결정 사항

- 위 표기 요구사항을 WPR559(생산실적등록) 화면에 반영하기로 함 — 실제 반영 내역은 [[신진SM MES 수정사항 (26.09.08)]] 참고 (포장수량>수주수량 시 행 색상 강조, 출하량 컬럼, `ITEM_KIND2` 기준 도면가공 필터 콤보 추가)
