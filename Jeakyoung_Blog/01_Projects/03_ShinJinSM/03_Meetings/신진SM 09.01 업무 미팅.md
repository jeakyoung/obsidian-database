## 💬 논의 내용

### POP

- 작지 분할 시: 100건에 대해 같은 공정을 다른 두 설비로 나눌 경우, 한쪽에서 50개 생산 중일 때 다른 쪽에서 50개를 찍으려 하면 정상적으로는 막혀 있음. 다만 두 설비 모두 작업 시작 전 수주정보를 입력해두고 "작업시작 대기" 상태로 있을 경우, 생산 중인 항목인지 체크하는 로직이 우회됨
  - 대응 방향: 완료 시 수주생산량 대비 생산량을 체크해서 저장을 막는 로직 추가 필요
- 도면가공 시에만 품목코드를 임의로 조회해서 채우지 말고, 빈 값으로 넘겨서 수주정보 내용을 그대로 따라가도록 조치 필요 (도면가공이 아닐 때는 기존 로직 유지)

### MES

- 재고 조정: 테스트 후 피드백 반영 필요
- 에러리스트 신규 페이지 개발 필요: MES상에서 포장 중복이 발생한 수주 건을 조회할 수 있는 기능 추가 (체크박스 등)
- 실재고가 있는데 포장입고가 잡히는 경우 확인 필요
- 생산실적등록에서 도면가공에 대한 데이터를 별도로 조회할 수 있게 해야 함
