## 💬 논의 내용

**회의 목적:** 포장 중복 문제, 성능 최적화, 재고 보정 관련 기술 검토

### 1. 포장 중복 문제 (우선순위: 높음)

**현황:**
- 제품창고 - 절단공정에서 발생
- 처리 중 타임아웃으로 롤백되는 경우, 동일 작업 재진행 시 중복 발생
- MES: 포장 원천 차단 완료
- ERP: 중복 데이터 발생 (마이너스 데이터)

**문제점:**
- MES에서는 롤백 정상 작동
- ERP에서는 롤백이 미작동
- 시스템 완료 피드백이 올 때도 실제로는 미완료 상황 발생

**기술 검토 필요:** MES/ERP 트랜잭션 동기화 메커니즘, 롤백 처리 순서 및 조건

### 2. 성능 최적화 / 속도 개선 (우선순위: 매우 높음)

**현황:**
- 길이 절단 로그 쌓기 필요
- 현재 포장, 출하쪽만 로깅 완료

**필요 조치:**
- 길이 절단 공정 로그 추가
- 성과 확인 방법: 시간대/횟수별 튀는 현상 수치화
- 타임아웃 시 fallback 후 자동 재시도 설정

### 3. 재고 보정 (우선순위: 높음)

**범위:** 창고별 재고 보정 필요

**구체적 항목:**
- 계정 대체 입고 등록
- 공장(1000) → 제품 → 상품창고(정남) → 수불상태 확인

### 기술 상세 내용 — ERP/MES 연동 방안

**문제:** MES 내에서도 오류 발생, MES/ERP 간 완료 상태 불일치

**해결 방안(이 시점 제안):** `SP_WMA624_01_IUD` 저장 동작 시 더존 `UP_PU_ITR_UPDATE` 함수를 함께 호출해서 ERP 상에도 자동 반영되도록 수정

> [!note] 실제 구현은 이후 달라졌다
> 이 회의에서 제안된 "UPDATE 한 번 더 호출" 방식은 실제로는 헤더/라인 분리 INSERT 구조(`NEOE.CP_GETNO` 배치 채번 + `UP_PU_MM_QTIOH_INSERT`/`UP_PU_ITR_INSERT`/`UP_PU_CGI_INSERT`)로 바뀌어 구현됐다. 현재 동작 기준 문서는 [\[통합\] 더존ERP 동기화](<../04_References/[통합] 더존ERP 동기화.md>) 참고.

**`SP_WMA624_01_IUD` 소스 백업 (2026-06-08 오전 10:44 스크립트 시점):**

```sql
USE [iPlusERP_SJ]
GO
/****** Object:  StoredProcedure [dbo].[SP_WMA624_01_IUD]    Script Date: 2026-06-08 오전 10:44:37 ******/
SET ANSI_NULLS ON
GO
SET QUOTED_IDENTIFIER ON
GO

ALTER PROC [dbo].[SP_WMA624_01_IUD]
(
	  @FACTORY_CODE				VARCHAR(6)
	, @IO_NO					VARCHAR(12)
	, @IO_FLAG					VARCHAR(3)
	, @ACC_FLAG					VARCHAR(6)
	, @MATERIAL_CODE			VARCHAR(30)
	, @ALTER_MATERIAL_CODE		VARCHAR(30)
	, @IO_DATE					VARCHAR(8)
	, @IO_CHARGE				VARCHAR(10)
	, @IO_QTY					FLOAT
	, @OUT_WAREHOUSE_CODE		VARCHAR(6)
	, @OUT_LOCATION_CODE		VARCHAR(6)
	, @IN_WAREHOUSE_CODE		VARCHAR(6)
	, @IN_LOCATION_CODE			VARCHAR(6)
	, @REMARK					VARCHAR(255)
	, @OPMAN_CODE				VARCHAR(10)
	, @SYSTEM_LOT_NO			VARCHAR(30)
	, @ALTER_SYSTEM_LOT_NO		VARCHAR(30)
	, @EXPIRE_DATE				VARCHAR(8)
	, @MANUFACTURE_DATE			VARCHAR(8)
	, @PLANT_CODE				VARCHAR(10) = ''
	, @IRU						CHAR(2)

 )

 AS

 BEGIN
    DECLARE @OPTIME  VARCHAR(12),
            @CNT     INT,
            @ERR_MSG VARCHAR(1000)
	SET @OPTIME = REPLACE(REPLACE(REPLACE(CONVERT(VARCHAR(16), GETDATE(), 120), '-', ''), ':',''), ' ', '');

	IF @IO_NO = ''

		BEGIN
			DECLARE @DATE VARCHAR(12)
			SET @DATE = REPLACE(REPLACE(REPLACE(CONVERT(VARCHAR(10), GETDATE(), 120), '-', ''), ':',''), ' ', '');
			SELECT	@IO_NO = @DATE + RIGHT ('0000'+LTRIM(STR(ISNULL(MAX(SUBSTRING(IO_NO,9,4)), 0) + 1)),4)
			FROM	TMA536 with(nolock)
			WHERE	SUBSTRING(IO_NO,1,8) = @DATE

		END


	IF @IRU = 'IU'
		BEGIN

        IF @IO_FLAG = '2'
        BEGIN

        BEGIN TRY
        SELECT @CNT = COUNT(*)
	    FROM ESMMTGL AS A

	        -- 재고량 정보 JOIN
            LEFT JOIN (
            SELECT SUM(MAT.IN_QTY) - SUM(MAT.OUT_QTY) AS STOCK_QTY,
                MAT.FACTORY_CODE,
                MAT.PLANT_CODE,
                MAT.WAREHOUSE_CODE,
                MAT.MATERIAL_CODE,
                MAT.SYSTEM_LOT_NO
                FROM TMA922M MAT
                GROUP BY MAT.FACTORY_CODE, MAT.PLANT_CODE, MAT.WAREHOUSE_CODE, MAT.MATERIAL_CODE, MAT.SYSTEM_LOT_NO
            ) AS MAT
            ON MAT.FACTORY_CODE = '000001'
            AND MAT.PLANT_CODE = @PLANT_CODE
            AND MAT.WAREHOUSE_CODE = @OUT_WAREHOUSE_CODE
            AND A.ITEM_CD = MAT.MATERIAL_CODE
            AND MAT.SYSTEM_LOT_NO = @SYSTEM_LOT_NO

            LEFT JOIN(
			SELECT	A.FACTORY_CODE
			,	A.PLANT_CODE
			,	A.WAREHOUSE_CODE
			,	A.SYSTEM_LOT_NO
			,	A.MATERIAL_CODE
			,	SUM(A.IN_QTY) - SUM(A.OUT_QTY) AS TARGET_QTY
		    FROM	TMA922 A
		    WHERE	A.PLANT_CODE = @PLANT_CODE
		    AND		(@OUT_WAREHOUSE_CODE = '' or (@OUT_WAREHOUSE_CODE <> '' and A.WAREHOUSE_CODE = @OUT_WAREHOUSE_CODE))
		    AND		A.IO_DATE <= @IO_DATE
            AND     A.SYSTEM_LOT_NO = @SYSTEM_LOT_NO
		    GROUP BY	A.FACTORY_CODE
			        ,	A.PLANT_CODE
			        ,	A.WAREHOUSE_CODE
			        ,	A.SYSTEM_LOT_NO
			        ,	A.MATERIAL_CODE
		    ) AS B
            ON MAT.FACTORY_CODE = B.FACTORY_CODE
            AND A.ITEM_CD = B.MATERIAL_CODE
            AND A.WERKS = B.PLANT_CODE

            LEFT JOIN TCO102 C
		    ON  MAT.FACTORY_CODE = C.FACTORY_CODE
		    AND MAT.PLANT_CODE = C.PLANT_CODE
            AND MAT.WAREHOUSE_CODE = C.WAREHOUSE_CODE

	    WHERE A.WERKS = @PLANT_CODE
	    and A.ITEM_CD = @MATERIAL_CODE
	    and MAT.WAREHOUSE_CODE =@OUT_WAREHOUSE_CODE
        AND MAT.SYSTEM_LOT_NO = @SYSTEM_LOT_NO
        --AND ((B.TARGET_QTY > @IO_QTY) AND MAT.STOCK_QTY - (B.TARGET_QTY - @IO_QTY) < 0)
        AND MAT.STOCK_QTY < @IO_QTY


        IF @CNT = 1
        BEGIN
            SET @ERR_MSG = '[LOT] ' + @SYSTEM_LOT_NO + ' 현재재고가 변경되어 수량이 부족합니다.'
            RAISERROR (@ERR_MSG,16,1) with log;
        END
        END TRY


        BEGIN CATCH
            SET @ERR_MSG = ERROR_MESSAGE()
            RAISERROR (@ERR_MSG,16,1) with log;
        END CATCH

        END
			UPDATE TMA536 SET
				IO_FLAG					=		@IO_FLAG
				,	ACC_FLAG			=		@ACC_FLAG
				,	MATERIAL_CODE		=		@MATERIAL_CODE
				,	ALTER_MATERIAL_CODE	=		@ALTER_MATERIAL_CODE
				,	IO_DATE				=		@IO_DATE
				,	IO_CHARGE			=		@IO_CHARGE
				,	IO_QTY				=		@IO_QTY
				,	OUT_WAREHOUSE_CODE	=		@OUT_WAREHOUSE_CODE
				,	OUT_LOCATION_CD		=		@OUT_LOCATION_CODE
				,	IN_WAREHOUSE_CODE	=		@IN_WAREHOUSE_CODE
				,	IN_LOCATION_CD		=		@IN_LOCATION_CODE
				,	REMARK				=		@REMARK
				,	OPMAN_CODE2			=		@OPMAN_CODE
				,	OPTIME2				=		@OPTIME
				,	SYSTEM_LOT_NO		=		@SYSTEM_LOT_NO
				,	ALTER_SYSTEM_LOT_NO	=		@ALTER_SYSTEM_LOT_NO
			WHERE FACTORY_CODE		=		@FACTORY_CODE
			AND IO_NO				=		@IO_NO

			IF	@@ROWCOUNT	=	0
				BEGIN

					INSERT INTO TMA536
					(
						FACTORY_CODE
						,IO_NO
						,IO_FLAG
						,ACC_FLAG
						,MATERIAL_CODE
						,ALTER_MATERIAL_CODE
						,IO_DATE
						,IO_CHARGE
						,IO_QTY
						,OUT_WAREHOUSE_CODE
						,OUT_LOCATION_CD
						,IN_WAREHOUSE_CODE
						,IN_LOCATION_CD
						,REMARK
						,OPMAN_CODE
						,OPTIME
						,SYSTEM_LOT_NO
						,ALTER_SYSTEM_LOT_NO
						,EXPIRE_DATE
						,MANUFACTURE_DATE
					)
					VALUES
					(
						@FACTORY_CODE
						,@IO_NO
						,@IO_FLAG
						,@ACC_FLAG
						,@MATERIAL_CODE
						,@ALTER_MATERIAL_CODE
						,@IO_DATE
						,@IO_CHARGE
						,@IO_QTY
						,@OUT_WAREHOUSE_CODE
						,@OUT_LOCATION_CODE
						,@IN_WAREHOUSE_CODE
						,@IN_LOCATION_CODE
						,@REMARK
						,@OPMAN_CODE
						,@OPTIME
						,@SYSTEM_LOT_NO
						,@ALTER_SYSTEM_LOT_NO
						,@EXPIRE_DATE
						,@MANUFACTURE_DATE
					)
				END
		END
	ELSE
		BEGIN
			DELETE FROM TMA536
			WHERE	FACTORY_CODE	=	@FACTORY_CODE
			AND				IO_NO	=	@IO_NO
		END
 END
```
