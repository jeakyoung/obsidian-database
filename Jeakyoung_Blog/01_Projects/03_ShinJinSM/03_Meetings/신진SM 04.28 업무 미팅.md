## 💬 논의 내용

### 출하 처리 중복 데이터 문제

- 출하 처리 삭제 시 같은 번호에 LOT만 다르게 중복이 생기는 현상 발생 (Long 값이 중복으로 나올 때)
- 중복 상태로 포장까지 완료된 경우, 특정 창고에 마이너스(-) 수량이 찍힘 — 중복 수량만큼 재고에 펑크가 남
- 이 작업 이전에도 오류 발생 시 중복 데이터가 간간히 있었음
- 미해결 쟁점: 출하 처리가 정상적으로 안 되는 원인이 "중복 데이터 삭제 로직 자체의 문제"인지 "별개의 오류"인지 아직 구분 안 됨

### 신진 서버 부하 / 쿼리 튜닝

- 부하 문제로 쿼리 튜닝 작업 진행 중 (출하 쪽 로깅도 같이 진행)
- 성과 확인 방법: 시간대·횟수별로 "튀는 현상"이 얼마나 잡혔는지 수치화 필요
- 대응 방향: 처리가 튀는(지연되는) 경우 타임아웃을 걸고 fallback 후 재시도하도록 설정

### 기타

- MES 서버 ↔ UPS 연결이 아직 안 되어 있음
- 매뉴얼을 플랫폼(관리자 매뉴얼 사이트)에 반영하기로 함

## ✅ 결정 사항

- 처리 지연 발생 시 타임아웃 후 fallback 재시도 방식으로 대응하기로 함
- 매뉴얼은 별도 문서가 아니라 플랫폼(관리자 메뉴얼 사이트)에 심는 방식으로 진행

## 🔜 후속 조치

- 쿼리 튜닝 + 출하 처리 로깅 계속 진행
- 지연 현상을 시간대·횟수 기준으로 수치화해 성과 측정 체계 마련
- MES 서버 ↔ UPS 연결 확인/구성
- 매뉴얼 플랫폼 반영 작업
