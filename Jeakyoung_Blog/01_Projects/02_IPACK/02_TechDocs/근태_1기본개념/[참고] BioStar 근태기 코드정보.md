# BioStar 근태기 코드 정보

## 📋 개요

| 항목 | 내용 |
|:--|:--|
| **대상 시스템** | BioStar 생체인식 근태기 → IPACK 근태 연동 |
| **적용 범위** | 근태기본 |
| **관련 모듈** | 미확인 (아래 참고) |

## 🎯 배경 및 요구사항

BioStar 생체인식 근태기에서 IPACK 시스템으로 출퇴근 기록이 연동된다. 근태기 쪽에 등록된 코드 목록을 기록해둔 문서.

## 🏗 설계 및 구현

### 수집 중인 코드 목록

다음 숫자 코드들이 BioStar 근태기 쪽에 등록되어 IPACK과 연동 중인 것으로 기록되어 있다:

```
544354658, 546839166, 546839168, 546839434, 546839480, 546839481,
546839595, 546839597, 546839598, 546839602, 546839603
```

> [!warning]
> 이 코드들이 정확히 무엇을 가리키는지(근태기 단말 시리얼 번호인지, 출입 이벤트 코드인지, 도어/디바이스 ID인지)는 이 문서에 근거가 남아있지 않다. `iPlusERP` 애플리케이션 소스(`WebContent/app`, `src/com`) 전체를 grep했으나 이 숫자들은 코드베이스 어디에도 나타나지 않는다 — BioStar 근태기 자체의 관리 콘솔/DB 설정값일 가능성이 높고, IPACK 애플리케이션 코드가 다루는 영역 밖일 수 있다. 미확인으로 남긴다.

### TIN334 관련 메모

문서 원본에 "TIN334 조회 가능"이라는 메모가 있었으나, `iPlusERP` 소스 전체를 grep해도 `TIN334`가 등장하는 파일이 없다. WHR313(기간별 근태현황) 문서([[01_Projects/02_IPACK/02_TechDocs/근태_4유지보수/[완료] 2025년 하반기 유지보수|2025년 하반기 유지보수]])에서도 TIN334를 언급하지만 이 역시 서블릿 소스(`jvWHR313_LIST.java`, `jvWHR313_IUD.java`)에는 나타나지 않고, SP(`SP_WHR313_01_LIST`, `SP_WHR313_01_IUD`) 내부에서만 쓰일 가능성이 있다 — SP 소스가 레포에 없어 확인 불가.

### 데이터 수집 흐름 (추정)

```
BioStar 근태기 → 출퇴근 기록 수집 → IPACK 연동 → 근태 구분 코드로 변환 → 근태 데이터 저장
```

이 흐름 자체도 일반적인 생체인식 근태기 연동 구조를 근거로 한 추정이며, IPACK 쪽 연동 배치/인터페이스 코드는 이 레포에서 확인하지 못했다.
