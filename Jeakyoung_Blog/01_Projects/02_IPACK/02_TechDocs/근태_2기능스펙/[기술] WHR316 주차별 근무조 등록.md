# WHR316 주차별 근무조 등록 기능 상세 스펙

## 📋 개요

| 항목 | 내용 |
|:--|:--|
| **대상 시스템** | iPlusERP (Sencha Ext JS + Java 서블릿) |
| **적용 범위** | 근태기능 |
| **관련 모듈** | `WHR316_VW.js`, `WHR316_CT.js`, `WHR316_ST.js`, `jvWHR316_IUD.java`, `jvWHR316_LIST.java` |

## 🎯 배경 및 요구사항

선택된 월의 주차별로 근무조를 개별 등록할 수 있는 기능. 개발 기간 2025-09-08 ~ 2025-09-16, 담당 안재경.

> [!note]
> 아래 Phase 구분과 세부 항목은 실제 작업 이력([[01_Projects/02_IPACK/01_Tasks/iPACK주차별 근무조 등록 (WHR316)/iPACK주차별 근무조 등록 (WHR316)|원본 작업 기록]])의 날짜와 전달 문서(`업무_전달-안재경*.pdf`) 시점을 근거로 재구성한 것이다.
