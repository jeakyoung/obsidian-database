## 🔍 현상 및 원인

부서 검색 필드(`columns_tf01`)에 값을 넣고 지울 방법(clear 트리거)이 없었음.

## 🔧 조치 내용

---

### 수정사항

```javascript
{
                                            xtype: 'textfield',
                                            reference: 'columns_tf01',
                                            itemId: 'columns_tf01',
                                            margin: '0 25px 0 0',
                                            labelAlign: 'right',
                                            fieldLabel: '부서',
                                            labelSeparator: ' ',
                                            labelWidth: 90,
                                            editable: false,
                                            triggers: {
                                                search: {
                                                    cls: 'x-fa fa-search',
                                                    handler: 'onOpenWindow',
                                                },
                                                clear: {
                                                    cls: 'x-form-clear-trigger',
                                                    hidden: true,
                                                    hideOnReadOnly: false,
                                                    handler: 'onClearTrigger',
                                                },
                                            },
                                            listeners: {
                                                change: 'onComboChange',
                                            },
                                        },
```

다음과 같이 트리거와 리스너를 선언해주었습니다.

```javascript
onClearTrigger: function (dv) {
        var me = this;
        var grid = dv.up('grid');

        switch (dv.itemId) {
            case 'columns_tf01': {
                dv.setValue('');

            }

            case 'combo_06': {
                dv.setValue('');
                break;

```

이후 트리거 동작 을 선언하여 동작시 value를 빈값으로 만들어줍니다.

```javascript
onComboChange: function (dv, newValue, oldValue, eOpts) {
        var me = this;

        switch (dv.itemId) {
            case 'cbo_Factory': {
                me.onView();
                break;
            }
            case 'columns_tf01': {
                if (newValue) {
                    dv.getTrigger('clear').show();
                } else {
                    dv.getTrigger('clear').hide();
                }
            }
```

기존에 있던 항목을 리스너로 사용하여 새로운 값을 받을경우 clear트리거를 보여주고 없다면 안보여 주는

식으로 구현했습니다.
