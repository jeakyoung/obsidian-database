> [[팀스페이스 이벤트 실 데이터 연동]]으로 events가 채워진 다음 순서. 날짜 하나에 이벤트를 어떻게 펼쳐 보여줄지가 관건이었음

## 🔍 현상 및 원인

`ScheduleTimeline`이 `DUMMY_SCHEDULE` 상수를 직접 참조 중이었다. 문제는 더미 데이터랑 실 데이터 구조가 아예 다르다는 것 — 더미는 "하루 = 한 행 + 활동 문자열 배열"이었는데, 실 데이터(`TripEvent`)는 "이벤트 = 시작일~종료일 범위 + 제목/장소"라 그대로 옮겨 끼울 수가 없었다. 날짜 포맷 변환("2026-08-01" → "08.01", 요일 등)을 해주는 유틸도 없었음.

## 🔧 조치 내용

| 구분 | 대상 | 변경 내용 |
|:--|:--|:--|
| 유틸 | `lib/date.ts` | `formatMonthDay()`, `getKoreanDay()` 추가 |
| 화면 | `ScheduleTimeline` | `events: TripEvent[]` prop 수신, `DUMMY_SCHEDULE` 제거 |

```typescript
export function formatMonthDay(dateStr: string): string {
  const [, month, day] = dateStr.split("-");
  return `${month}.${day}`;
}

export function getKoreanDay(dateStr: string): string {
  const days = ["일", "월", "화", "수", "목", "금", "토"];
  return days[new Date(dateStr).getDay()];
}
```

멀티데이 이벤트(`startDate` ≠ `endDate`)는 그 기간에 걸친 날짜마다 하루씩 펼쳐서 `Map<날짜, TripEvent[]>`로 만들고, 날짜 오름차순으로 최대 4개까지만 노출. 이벤트가 여러 개인 날은 색상 dot + 제목 칩으로 전부 나열하는 쪽으로 결정했다(대시보드 요약 화면이라 하루에 이벤트가 그렇게 많지 않을 거라 판단, `+N개` 접기는 안 함).
