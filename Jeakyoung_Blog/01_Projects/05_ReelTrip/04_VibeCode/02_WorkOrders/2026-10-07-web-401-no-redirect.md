## 요구사항 분석 요약

- `attemptRefresh()`의 `refresh_token` 부재 분기만 세션 정리/리다이렉트가 빠져 있고, 나머지 두 실패 분기(재발급 API 실패, API 응답 실패)는 동일한 처리를 이미 하고 있음 — 동일한 패턴으로 통일하면 됨.
- 모호한 부분 없음 — 기존 코드에 이미 있는 처리(세션 정리 + `/auth/login` 리다이렉트)를 누락된 분기에 그대로 추가하는 단순 수정.

## 작업 계획

### 1단계: 분석 및 준비
- [x] `attemptRefresh()` 내 3개 분기 비교, 누락 지점 확인

### 2단계: 구현
- [x] `if (!refreshToken) return null;` → 세션 정리 + `/auth/login` 리다이렉트 후 `null` 반환으로 수정

- [x] 수정 후 `type-check` 통과 확인 (`npx tsc --noEmit` 에러 없음)
