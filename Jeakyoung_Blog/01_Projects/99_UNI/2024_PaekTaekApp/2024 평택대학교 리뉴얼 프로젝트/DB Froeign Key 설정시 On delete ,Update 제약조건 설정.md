### **제약조건**

#### **1. RESTRICT**

개체를 변경, 삭제 시 다른 개체가 변경, 삭제할 개체를 참조하는 경우 변경,삭제가 취소됨

#### **2. CASECADE**

개체를 변경, 삭제 시 다른 개체가 변경, 삭제할 개체를 참조하는 경우 모두 변경, 삭제됨

#### **3. NO ACTION**

MySQL 기준 RESTRICT와 동일

#### **4. SET NULL**

개체를 변경, 삭제 시 다른 개체가 변경, 삭제 시 개체를 참조하는 경우 참조 값을 NULL로 세팅
