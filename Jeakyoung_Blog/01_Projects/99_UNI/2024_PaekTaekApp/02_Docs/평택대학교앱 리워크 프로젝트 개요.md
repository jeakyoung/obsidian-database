# 평택대학교앱 리워크 프로젝트 개요

## 📋 개요

| 항목 | 내용 |
|:--|:--|
| **프로젝트** | 대학프로젝트 |
| **기간** | 2024-03 ~ 2024-12 (중단) |
| **역할** | BE 팀장 · PL — API 서버(`4th_GraduationBack`) 전담 |
| **기술 스택** | Spring Boot 3(Java 17), Spring Data JPA, MariaDB(AWS RDS), React Native 0.73 |

> 평택대학교 공식 앱의 안 쓰는 기능을 걷어내고 처음부터 다시 만든 졸업(4학년) 프로젝트. 학사/입학/장학/공지 게시판, 회원가입·로그인, 이메일 인증, 이미지 첨부까지 백엔드 기능은 붙였으나 샘플 DB 유출 사고로 2024년 12월 중단됐다.

## 🎯 목표 및 범위

- **일반적 의도**: 평택대학교 구형 공식 앱에 안 쓰이는 기능이 많다고 판단, 애자일 방식으로 빠르게 프로토타입을 뽑아 실제 사용자 경험을 검증하고자 함.
- **개인적 의도**: 프로젝트를 직접 리드해서 앱 개발의 시작부터 끝, 이후 유지보수까지 한 사이클을 경험해보는 것.
- **구체적 목표**: 완성한 프로토타입을 구글 플레이스토어/앱스토어에 정식 출시해 학교 공식 앱을 대체하는 것.
- **범위 (BE, `4th_GraduationBack`)**: 회원가입/로그인, 공지·학사·입학·장학 4종 게시판 CRUD, 이메일 인증, 이미지 업로드, 학과 코드 매핑.

## 🏗 진행 내용

| 저장소 | 경로 |
|:--|:--|
| Back-End | `4th_GraduationBack` (Spring Boot) |
| Front-End | `4th_GraduationFront` (React Native) |

- 개발 관리는 Jira(프로젝트 키 `ANRYU`)로 백로그·스프린트를 운영했고, 디자인은 Figma(`PTU_Remake`)로 별도 관리했다.
- 팀 구성 (총 6명, BE 2 · FE 3 · 디자인 겸 FE 1):

| 이름 | 역할 | 비고 |
|:--|:--|:--|
| 안재경 (본인) | BE 팀장, PL | API 서버 설계·구현 전담 |
| 이종태 | BE 지원, 보안 개발 | 이메일 인증 SMTP 계정 운영 |
| 류채현 | FE 팀장 | |
| 박미현 | UI/UX 디자인, FE | Figma 디자인 담당 |
| 안정연 | FE 개발 | |
| 이하윤 | FE 개발 | |

- BE 쪽에서 실제로 진행한 작업은 [[01_Projects/99_UNI/2024_PaekTaekApp/01_Tasks|작업 목록]] 참고. 회원가입 절차를 ID/학번/이메일 단계로 쪼개고 SALT 기반 해싱을 붙인 것, 게시판 4종에 이미지 첨부를 붙인 것, 이메일 인증 코드 발송 기능이 핵심.
- 2024년 12월, 샘플 데이터베이스 유출 사고가 발생해 프로젝트가 임시 중단됐고 이후 재개되지 않았다.

## ✅ 결과 및 회고

- 정식 출시(스토어 배포)까지는 못 갔다 — 게시판 CRUD·회원가입·이메일 인증까지는 백엔드 기능이 붙었지만, DB 유출 사고로 중단된 이후 재개되지 않았다.
- 백엔드 저장소(`4th_GraduationBack`)의 GitHub 커밋 히스토리가 `4th_Graduation_backend` 커밋 1개로 뭉쳐 있다 — 원래 Eclipse 로컬에서 작업하다 GitHub로 옮기는 과정에서 세부 이력이 사라진 것으로 보인다. 개발 중 실제로 겪은 문제(회원가입 UX, Git 병합 충돌 등)는 [[01_Projects/99_UNI/2024_PaekTaekApp/01_Tasks|작업 목록]]에 남겨둔 개인 기록 기준으로 정리했다.
- 자세한 회고는 [[평택대학교앱 리워크 개발 과정]] 참고.
