# 데이터 바우처 이미지 업로드 거래처코드 선택값 전환 09.18

## 📋 개요

| 항목 | 내용 |
|:--|:--|
| **요청자** | — |
| **요청일** | 2026-09-18 |
| **대상 시스템** | F1Soft.Starmap.Service — Image |
| **관련 화면·프로그램** | `UploadImageRequest` |

> `UploadImageRequest.CustomerCode`를 필수(`[Required]`)에서 선택값(`string?`)으로 전환 — 거래처 없이 라벨만 단독 등록하는 케이스 지원.

## 🔍 현상 및 원인

### 재현 조건

라벨 이미지를 거래처 연결 없이 단독으로 등록해야 하는 케이스에서 `CustomerCode` 필수 검증에 막힘.

### 원인

`UploadImageRequest.CustomerCode`가 `[Required] string`으로 선언되어 있어, `TB_LabelMaster.SUPPLIER_CODE`를 채울 거래처가 없는 "단순 라벨 등록" 시나리오를 표현할 수 없었다. 같은 모델의 `MaterialCode`는 이미 "거래처 단독 등록 시 생략 가능"이라는 주석과 함께 `string?`로 선택값 처리되어 있어 대칭이 맞지 않았다.

## 🔧 조치 내용

| 구분 | 대상 | 변경 내용 |
|:--|:--|:--|
| 모델 | `Models/Image/UploadImageRequest.cs` | `CustomerCode`에서 `[Required]` 제거, 타입을 `string` → `string?`로 변경, 주석에 "단순 라벨 등록 시 생략 가능" 명시 |

## ✅ 검증 및 결과

- [ ] `CustomerCode` 미전달 시 업로드 성공 확인
- [ ] `CustomerCode` 없이 저장된 라벨의 `TB_LabelMaster.SUPPLIER_CODE`가 어떤 값으로 들어가는지(NULL/빈문자열) `ImageService` 저장 로직 쪽 확인 필요
- [ ] 커밋 및 관련 SP(`SP_LABEL_*`)의 `SUPPLIER_CODE` NULL 허용 여부 확인
