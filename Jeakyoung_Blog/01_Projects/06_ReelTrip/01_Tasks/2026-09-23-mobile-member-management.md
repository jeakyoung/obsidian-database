## 작업 결과 요약

모바일에 웹 `MemberScreen`과 동등한 멤버 전체 목록 조회 + 소유자 전용 멤버 내보내기 기능을 추가했다. 기존에 정의만 되어 있고 사용처가 없던 `removeMember` API를 이번에 처음 연결했다.

## 변경 사항 상세

### 삭제 확인 다이얼로그

웹 `MemberScreen`은 확인 없이 즉시 "내보내기"가 실행되지만, 모바일은 되돌리기 어려운 액션이라 `Alert.alert`로 "취소/내보내기(destructive)" 확인을 거치도록 구현했다. 작업지시서에서 사용자 컨펌을 받은 항목이다.

**변경 이유:**
- 모바일 환경에서는 실수로 인한 탭이 잦고, 삭제 후 되돌릴 UI 경로가 없어 확인 절차를 추가하는 것이 안전.

### 목록 갱신 방식

`MemberModal`은 `currentSpace`(`useTravelData` → `useSpaces()` 결과)를 그대로 prop으로 받아 렌더링하므로, 삭제 성공 시 `useInvalidateSpaces()`로 `spaces` 쿼리만 무효화하면 모달과 `SpaceInfo` 아바타 미리보기가 함께 갱신된다. 별도의 로컬 상태 동기화 로직은 두지 않았다.
