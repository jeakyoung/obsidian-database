## 📋 프로젝트 개요

IPACK은 근태 관리, 매출 처리, 수주 승인 등의 핵심 기능을 담당하는 시스템으로, 지속적인 유지보수 및 기능 개선 진행 중

### 주요 작업 영역

- 매출 마감 처리 기능
- 수주 승인 프로세스
- BioStar 연동

## 🔧 주요 기술 영역

### 근태 관리
- 출퇴근 시간 기록
- 주차별 근무조 설정
- 기간별 근태 현황 조회
- 시간 계산식 (ceil/floor/round)

### 매출 처리
- 매출 마감 프로세스
- 데이터 검증
- 리포트 생성

### 수주 관리
- 수주 등록
- 승인 워크플로우
- 통계 및 분석

### BioStar 연동
- 근태기 데이터 수신
- 데이터 동기화
- 오류 처리
