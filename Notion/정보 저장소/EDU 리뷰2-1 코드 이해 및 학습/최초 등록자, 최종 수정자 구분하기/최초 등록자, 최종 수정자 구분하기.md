## 코드 수정안

```sql
ALTER PROCEDURE [dbo].[SP_HHR102_IUD]
    @FACTORY_CODE           VARCHAR(6),
    @WORK_CODE              VARCHAR(6),
    @LINE_CODE              VARCHAR(3),
    @LINE_NAME              VARCHAR(50),
    @VIEW_SEQ               INT,
    @PROD_LIMIT_QTY         FLOAT,
    @OPMAN_CODE             VARCHAR(4),         //등록자 저장을 위한 호출
    @OPMAN_CODE2            VARCHAR(4),         //수정자 저장을 위한 호출
    @LINE_INSP_DATE         VARCHAR(24),
    @IMPORTANT_LINE_FLAG    VARCHAR(1),
    --@DELETE_FLAG            VARCHAR(2),
    @IUD                    VARCHAR(4)
AS
BEGIN
    
    DECLARE @DATE varchar(25)
	SET @DATE = replace(replace(replace(convert(varchar(20), getdate(), 120), '-', ''), ':',''), ' ', '');

    IF @IUD = 'IU'
    BEGIN
        UPDATE HHR102
        SET
            LINE_NAME           = @LINE_NAME,
            VIEW_SEQ            = @VIEW_SEQ,
            PROD_LIMIT_QTY      = @PROD_LIMIT_QTY,
            OPMAN_CODE2         = @OPMAN_CODE2,           //업데이트 시에는 수정자로 저장
            OPTIME2             = @DATE,                  //date는 공용이지만 OPTIME2로 수정시각 저장
            LINE_INSP_DATE      = @LINE_INSP_DATE,
            IMPORTANT_LINE_FLAG = @IMPORTANT_LINE_FLAG,
            DELETE_FLAG         = '0'
        WHERE
            FACTORY_CODE        = @FACTORY_CODE 
            AND WORK_CODE       = @WORK_CODE 
            AND LINE_CODE       = @LINE_CODE

        IF @@ROWCOUNT = 0
         BEGIN
            IF ( @LINE_CODE = '' AND @VIEW_SEQ = '' )
                BEGIN
                    SELECT @LINE_CODE = RIGHT('000' + CAST(CAST(ISNULL(MAX(LINE_CODE),'0') AS INT) + 1 AS VARCHAR(3)),3),
                           @VIEW_SEQ  = ISNULL(MAX(VIEW_SEQ),　0) + 1 
                    FROM   HHR102 
                    WHERE  WORK_CODE  = @WORK_CODE
                END


            INSERT INTO HHR102 (
                FACTORY_CODE,
                WORK_CODE,
                LINE_CODE,
                LINE_NAME,
                VIEW_SEQ,
                PROD_LIMIT_QTY,
                OPMAN_CODE,                              //신규 등록시 OPMAN_CODE로 저장
                OPMAN_TIME,                              //신규 등록 시각 저장
                LINE_INSP_DATE,
                IMPORTANT_LINE_FLAG
            ) VALUES (
                @FACTORY_CODE,
                @WORK_CODE,
                @LINE_CODE,
                @LINE_NAME,
                @VIEW_SEQ,
                @PROD_LIMIT_QTY,
                @OPMAN_CODE,
                @DATE,
                @LINE_INSP_DATE,
                @IMPORTANT_LINE_FLAG
            );
        END
    END

    ELSE IF @IUD = 'D'
    BEGIN
        UPDATE HHR102
        SET DELETE_FLAG = '1'
        WHERE
            FACTORY_CODE     = @FACTORY_CODE
            AND WORK_CODE    = @WORK_CODE
            AND LINE_CODE    = @LINE_CODE
    END

        DECLARE    @count INT;
        SELECT     @count = COUNT(*)
        FROM HHR102 A
            LEFT JOIN HHR101 B
                ON A.WORK_CODE    = B.WORK_CODE
        WHERE   A.FACTORY_CODE    = @FACTORY_CODE
            AND A.WORK_CODE       = @WORK_CODE
            AND ISNULL(A.DELETE_FLAG, '0') <> '1'
        UPDATE HHR101
            SET   LINE_COUNT        = @count
            WHERE FACTORY_CODE      = @FACTORY_CODE
                  AND WORK_CODE     = @WORK_CODE
END
```

해당 부 등록을 위해 이미 프로시저에서 I동작과 U동작을 ROWCOUNT를 필터로 사용해 구분하고 있기에  동작시마다

저장부를 별게로 설정해주면 가능합니다. UPDATE시 OPMAN2에 수정자, 시간을 저장하면 되고 INSERT 동작시에는

기존방법대로 OPMAN에 등록시간 등록자를 저장하면 됩니다.
