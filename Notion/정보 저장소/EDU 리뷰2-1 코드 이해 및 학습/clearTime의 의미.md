# Ext_DOC상의 clearTime 정의

![[image 51.png]]

clearTime ( date, [clone] )

- 모든 시간정보를 삭제하고자 할때 정오시간을 같은날로 세팅한다. 
- 이를 적용할때 자동으로 썸머타임도 적용한다

파라미터로는 date와 clone가 들어가는데 clone으로 true값을 넘겨줄 경우 날짜를 clone해서 시간을 

지우고 반환한다

리턴값: Date 나 clone 값

예상되는 사용이유 : 해외에서 적용되는 썸머타임을 T/F값으로 자동적용하기 위해.

# DST가 적용되었을때 시간자동계산에서의 문제점

썸머타임 적용시 특정 기간동안 1시간이 밀리게 됨  → 3월 28일 시작에 10월31일 종료로 치면

28일 기준으로 하루가 23시간이 되고 31일 기준으로는 하루가 25시간이 된다. 

때문에 24시간 단위 계산을 지속하는 환경이면 **하루가 밀리게 된다.**
