서블릿의 생명주기(Lifecycle)는 서블릿이 생성되고 실행되는 과정을 나타냅니다. 이 과정은 다음 세 가지 단계로 나뉩니다: 초기화(init), 서비스(service), 소멸(destroy)입니다.

### **초기화(Initialization) - init() 메서드**

- 서블릿 인스턴스가 처음으로 생성될 때 호출됩니다.
- 서블릿 컨테이너는 서블릿을 초기화하기 위해 `**init()**` 메서드를 호출합니다.
- `**init()**` 메서드는 서블릿이 사용할 자원을 초기화하거나, 설정 값을 읽어들이는 등의 작업을 수행합니다.
- `**init()**` 메서드는 서블릿 생명주기에서 단 한 번만 호출됩니다.

### **서비스(Service) - service() 메서드**

- 클라이언트의 요청이 서블릿으로 전송될 때마다 호출됩니다.
- 서블릿 컨테이너는 각 요청에 대해 `**service()**` 메서드를 호출하여 요청을 처리합니다.
- `**service()**` 메서드는 요청의 HTTP 메서드(GET, POST, PUT, DELETE 등)에 따라 적절한 메서드(doGet(), doPost() 등)를 호출합니다.
- 개발자는 서비스 메서드를 오버라이드하여 클라이언트의 요청을 처리하고 응답을 생성합니다.

### **소멸(Destruction) - destroy() 메서드**

- 서블릿 인스턴스가 소멸되기 전에 호출됩니다.
- 서블릿 컨테이너는 서블릿을 제거하기 전에 `**destroy()**` 메서드를 호출하여 서블릿이 사용한 자원을 해제합니다.
- `**destroy()**` 메서드는 서블릿 컨테이너가 종료되거나 서블릿이 언로드될 때 호출됩니다.
- `**destroy()**` 메서드는 서블릿 생명주기에서 단 한 번만 호출됩니다.

```javascript
            +------------+
            | Init       |
            | (init())   |
            +-----+------+
                  |
                  v
            +-----+------+
            | Service    |
            | (service())|
            +-----+------+
                  |
                  v
            +-----+------+
            | Destroy    |
            | (destroy())|
            +------------+

```

### **서블릿 생명주기 특징**

- 서블릿은 클라이언트의 요청이 있을 때마다 생성되고 초기화되지 않습니다. 대신, 서블릿 컨테이너가 관리하며 필요에 따라 생성됩니다.
- 각 요청마다 새로운 스레드가 생성되며, 스레드가 요청을 처리하는 동안에는 해당 서블릿 인스턴스의 `**service()**` 메서드가 호출됩니다.
- 서블릿은 개발자가 직접 생성하거나 소멸시키지 않습니다. 대신, 서블릿 컨테이너가 이를 관리합니다.
