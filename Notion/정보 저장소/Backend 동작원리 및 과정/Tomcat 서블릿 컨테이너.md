1. **서블릿 관리**: 서블릿 컨테이너는 웹 애플리케이션에 등록된 서블릿을 관리합니다. 서블릿의 생명주기를 관리하고, 요청에 따라 서블릿을 인스턴스화하고 초기화합니다.
2. **요청 처리**: 클라이언트로부터의 HTTP 요청을 처리합니다. 요청이 들어오면 해당 요청을 처리할 서블릿을 찾고, 서블릿에 요청을 전달하여 응답을 생성합니다.
3. **응답 생성**: 서블릿 컨테이너는 서블릿이 생성한 응답을 클라이언트에게 반환합니다. 이를 통해 동적인 웹 페이지를 생성하고 클라이언트에게 제공할 수 있습니다.
4. **스레드 관리**: 서블릿 컨테이너는 다중 스레드 환경에서 요청을 처리하기 위한 스레드 풀을 관리합니다. 각 요청은 별도의 스레드에서 처리되며, 스레드 풀을 통해 효율적인 리소스 관리가 가능합니다.
5. **세션 관리**: 웹 애플리케이션의 세션 관리를 제공합니다. 클라이언트의 세션 식별자를 유지하고 세션 데이터를 관리하여 사용자 상태를 유지합니다.
6. **보안 관리**: 서블릿 컨테이너는 보안 관련 기능을 제공하여 웹 애플리케이션의 보안을 강화합니다. SSL/TLS 지원, 사용자 인증 및 권한 부여, 보안 설정 등을 제공합니다.
