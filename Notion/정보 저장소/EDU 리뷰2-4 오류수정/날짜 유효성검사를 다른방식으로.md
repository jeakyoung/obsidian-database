## 기존 검사 방식

```javascript
{
              xtype: 'datecolumn',
              align: 'center',
              width: 130,
              text: replaceLocale('예방점검일'),
              dataIndex: 'LINE_INSP_DATE',
              format: 'Y/m/d',
              editor: {
                xtype: 'datefield',
                format: 'Y/m/d',                              //입출력 포맷지정
                submitFormat: 'Y/m/d',
                minValue: new Date(),     //최소일자 지정, 오늘 이후여야 지정가능
                minText: '{0} 이후여야 합니다.'
              }
            },
```

데이트 칼럼에서 minValue를 사용하여 오늘날짜를 받아온뒤 minText로 오늘 이후여야 등록이 가능하다는

메시지를 출력하는 방식으로 진행했습니다.

## 다른 방식을 활용한 유효검사

![[image 31.png]]

```javascript
var selday = (rec.get('LINE_INSP_DATE') || '');

if (selday < new Date()) {
          Ext.Msg.alert('정보', '점검일은 오늘이후여야 합니다.');
          valid = false;                                                                                // 유효성 실패
          break;                                                                                        // 루프 중단
        }
```

다음과 같이 날짜에도 비교연산이 가능합니다. 이를 활용하여 onRegDetail 동작시 가져온 날짜 (방금 등록한 날짜)가 오늘 

날짜 보다 작다면 alert메시지를 출력하고 break를 걸어 변경사항을 롤백하는 방식으로 구현했습니다.
