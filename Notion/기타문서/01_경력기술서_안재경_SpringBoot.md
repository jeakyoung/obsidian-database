## 🔧 주요 프로젝트 경험

### 1. 신진SM ERP/MES 통합 시스템 개선 (2026년 4월 ~ 진행중)

**프로젝트 개요**
- 신진SM 사업장의 ERP/MES 연동 시스템의 안정성 및 성능 개선
- 포장 시스템의 중복 발생 문제 해결 및 재고 정확도 향상

**담당 역할**
- **포장 중복 문제 분석 및 해결 (진행중)**
  - MES/ERP 간 동기화 오류 원인 분석
  - 3가지 근본 원인 파악 및 4단계 해결 방안 수립
  - 중복 검증 로직 구현 및 타임아웃 재시도 메커니즘 추가
  
- **성능 최적화 (응답시간 30% 이상 개선 목표)**
  - SQL 쿼리 최적화 및 인덱스 재설계
  - 길이 절단 공정 로깅 추가를 통한 병목 지점 파악
  - 캐싱 메커니즘 도입 및 실시간 모니터링 대시보드 구축
  
- **재고 동기화 및 데이터 정합성 보장**
  - 마이너스 재고 현황 파악 및 정정 입고 등록 절차 정의
  - 데이터 마이그레이션 및 검증 프로세스 수립
  - 장부 재고와 실제 재고 100% 일치 달성 계획

**기술 스택:**
- Backend: Spring Boot, Java
- Database: PostgreSQL, SQL 쿼리 최적화
- ERP 연동: 더존 ERP API, Java 연동 코드

**성과:**
- 포장 중복 문제의 기술적 근본 원인 분석 완료
- 성능 최적화 계획 수립 (예상 30% 이상의 응답시간 개선)
- 데이터 동기화 메커니즘 정의 완료

### 2. IPACK 근태 관리 시스템 유지보수 (2025년 ~ 진행중)

**프로젝트 개요**
- 근태 관리, 매출 처리, 수주 승인 등 핵심 기능의 지속적인 유지보수 및 개선

**담당 역할**
- **근태 시스템 기술 개선**
  - 시간 계산 로직 개선 (ceil/floor/round 처리로 지각/조퇴/초과시간 구분)
  - 외출 조건 수정 (동일 날짜 조건으로 제한)
  - 근무조별 일근태등록 자동 계산 로직 구현
  
- **증명서 발급 기능 개선**
  - 주민번호 뒷자리 선택 가능하도록 수정
  - SP_WHR103_01_RPT 저장프로시저 수정
  - JSP UI 업데이트
  
- **부서 코드 동기화 문제 해결**
  - 개발/운영 환경의 DEPARTMENT_CODE 형식 불일치 (010072 vs 10072) 원인 파악
  - 데이터 정상 등록 프로세스 확인 및 문서화

**기술 스택:**
- Backend: Spring Boot, Java, SQL/PL-SQL
- Database: PostgreSQL
- 시스템 연동: BioStar 근태기 데이터 연동

**성과:**
- 2025년 하반기 유지보수 완료 (근무조별 일근태등록 기능 개선)
- 2026년 상반기 유지보수 완료 (엑셀활성화, 증명서발급)
- 시간계산 로직의 정확성 향상

### 3. I-Frog POS 시스템 - FCM 알림 및 성능 최적화 (2026년 6월 진행중)

**프로젝트 개요**
- 식품/외식업 POS 시스템의 실시간 주문 알림 기능 강화 및 성능 최적화

**담당 역할**
- **FCM(Firebase Cloud Messaging) 알림 시스템 구현**
  - 서버 세팅 및 기본 기능 개발
  - 실시간 주문 알림 시나리오 정의 (3가지)
  - API 엔드포인트 설계 (5개 이상)
  - 문제 해결 방법 정의 및 성능 최적화

- **데이터베이스 연결 및 최적화**
  - Connection Pool 설정
  - TGI003 테이블 구조 설계
  - 성능 최적화 기법 3가지 적용
  - 캐싱 전략 구현

- **환경별 설정 및 배포 가이드 작성**
  - 3가지 환경(개발/스테이징/운영)별 yml 완전 예제 작성
  - Docker/Kubernetes 배포 프로세스 정의
  - 보안 설정 및 환경변수 관리

**기술 스택:**
- Backend: Spring Boot, Java
- Database: PostgreSQL, Connection Pool (HikariCP)
- 메시징: Firebase Cloud Messaging (FCM)
- DevOps: Docker, Kubernetes, NginX 라우팅

**성과:**
- FCM 기본 기능 개발 완료
- 환경별 배포 가이드 및 yml 템플릿 완성
- 성능 최적화 계획 수립

### 4. NoNAME 프로젝트 - Backend 아키텍처 설계 (개인 학습 프로젝트, 진행중)

**프로젝트 개요**
- AI/LLM 기반 애플리케이션의 Spring Boot 백엔드 아키텍처 설계
- 신입 개발자의 기술 역량 강화를 목표로 진행 중

**담당 역할**
- **Backend 아키텍처 설계**
  - 계층별 설계 및 @Transactional 전파방식 가이드 (6가지)
  - PreparedStatement를 통한 SQL Injection 방지
  - Mybatis 동적 SQL 작성 및 N+1 문제 해결 (3가지 방법)

- **데이터베이스 최적화 연구**
  - 테이블 설계 정규화 및 인덱싱 전략 (5단계)
  - N+1 쿼리 패턴 분석 (3가지) 및 해결책 제시
  - Mybatis 고급 활용법 (8가지)
  - 쿼리 성능 분석 및 모니터링 기법

- **개발 환경 구성 및 협업 가이드**
  - Git Flow 워크플로우 정의
  - PR 체크리스트 및 코드 리뷰 표준 정의
  - 테스트 표준 정의
  - 온보딩 체크리스트 작성

**기술 스택:**
- Backend: Spring Boot, Java
- ORM: Mybatis (SQL 매퍼)
- Database: PostgreSQL
- 버전관리: Git Flow, GitHub
- 개발환경: Docker, IDE (IntelliJ IDEA)

**학습 성과:**
- N+1 문제 해결 방법 3가지 습득
- Mybatis 동적 SQL 및 고급 기법 습득
- 팀 협업 표준 및 Git Flow 워크플로우 이해
- DB 최적화 18개 섹션에 걸친 체계적 학습

## 💻 기술 스택 및 역량

### Backend Framework & Language
- **Spring Boot:** 프로젝트 구성, 의존성 관리, 자동 설정
- **Java:** 객체지향 설계, 디자인패턴, Exception 처리
- **SQL/PL-SQL:** 저장프로시저, 트리거, 쿼리 최적화

### Database
- **PostgreSQL:** 
  - 기본 CRUD 및 복잡한 쿼리 작성
  - 인덱스 설계 및 성능 분석
  - 연동 시스템 데이터 동기화
  
- **MSSQL:** 
  - 레거시 시스템 마이그레이션 경험
  - 저장프로시저 및 뷰 작성
  - 데이터 변환 및 검증

### ORM & Query Tools
- **Mybatis:** 동적 SQL, 복잡한 쿼리 매핑
- **Spring Data JPA:** 기본적인 repository 사용
- **Native Query:** 성능 최적화를 위한 직접 SQL 작성

### DevOps & Infrastructure
- **Docker:** 컨테이너 이미지 빌드 및 배포
- **Kubernetes:** 기본 개념 및 배포 가이드 작성
- **NginX:** 포트 라우팅 설정 및 로드 밸런싱

### 메시징 & 알림
- **Firebase Cloud Messaging (FCM):** 푸시 알림 서버 연동
- **실시간 모니터링:** 대시보드 구축

### 개발 도구 & 버전관리
- **Git / GitHub:** Git Flow 워크플로우
- **Jira:** 이슈 추적 및 프로젝트 관리
- **IDE:** IntelliJ IDEA, VS Code
