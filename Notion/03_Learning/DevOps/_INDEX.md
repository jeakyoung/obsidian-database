## 📚 빠른 참고

### 자주 사용하는 명령어

**NginX**
```bash
# 상태 확인
systemctl status nginx

# 시작/중지
systemctl start/stop nginx

# 재시작
systemctl restart nginx
```

**PostgreSQL**
```bash
# 클러스터 확인
pg_lsclusters

# 접속
psql -h localhost -p 5110 -U erpUser -d groupware_dev
```

**vi/vim**
```bash
# 편집 시작
vi /path/to/file.txt

# Insert 모드 진입
i

# 저장 후 종료
:wq
```

## 💡 사용 가이드

### 문제 해결 시
1. 관련 기술 참고 문서 확인
2. 명령어 실행으로 상태 확인
3. 필요시 배포 가이드 참고
4. 작업 기록으로 정리

### 새로운 배포 절차 추가 시
1. `배포가이드/` 폴더에 문서 생성
2. 파일명: `[기술] 모듈명 배포 가이드.md`
3. 단계별 프로세스 정의
4. 확인 체크리스트 포함

### 서버 작업 기록 추가 시
1. `시스템운영/` 폴더에 문서 생성
2. 파일명: `[작업] YYYYMMDD 작업 내용.md`
3. 작업 내용, 결과, 영향도 기록
