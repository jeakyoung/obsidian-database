# vi/vim 명령어 가이드

리눅스/Unix 환경에서 가장 널리 사용되는 텍스트 에디터 vi/vim의 필수 명령어 모음

---

## 🎯 vi/vim 개요

**vi:** 기본 에디터 (모든 Unix/Linux 시스템에 기본 포함)  
**vim:** vi의 향상된 버전 (추가 기능 포함)

### 시작하기
```bash
# 파일 열기/생성
vi /path/to/file.txt
vim /path/to/file.txt

# 읽기 전용으로 열기
vi -R /path/to/file.txt
```

---

## 🔄 모드 전환

vi/vim에는 3가지 주요 모드가 있습니다:

### 1️⃣ **일반 모드 (Normal Mode)**
- vi 시작 시 기본 모드
- 명령어 입력 모드
- 모드 전환: `Esc` 키로 돌아옴

### 2️⃣ **삽입 모드 (Insert Mode)**
- 텍스트 입력 모드
- 모드 진입: `i`, `I`, `a`, `A`, `o`, `O` 등
- 모드 탈출: `Esc`

### 3️⃣ **명령행 모드 (Command Line Mode)**
- 파일 저장, 종료 등 명령 실행
- 모드 진입: 일반 모드에서 `:` 입력
- 모드 탈출: `Esc`

---

## ✏️ 텍스트 입력 명령어 (삽입 모드 진입)

| 명령어 | 설명 | 예시 |
|--------|------|------|
| **i** | 현재 커서 위치에서 Insert 시작 | 커서: `\|abc` → `i` → `X\|abc` |
| **I** | 현재 줄 맨 앞에서 Insert 시작 | `  abc` → `I` → `\|  abc` |
| **a** | 현재 커서 다음 칸에서 Insert 시작 | 커서: `a\|bc` → `a` → `a\|bc` |
| **A** | 현재 줄 맨 뒤에서 Insert 시작 | `abc` → `A` → `abc\|` |
| **o** | 현재 줄 아래에 새 줄 생성 후 Insert | `abc` → `o` → `abc` / `\|` |
| **O** | 현재 줄 위에 새 줄 생성 후 Insert | `abc` → `O` → `\|` / `abc` |

**예시:**
```
원본 텍스트:
hello world

i 실행 (커서가 'w' 위치):
hello [입력 모드] world

결과:
helloXXX world  (XXX는 입력한 텍스트)
```

## 🎮 커서 이동 명령어 (일반 모드)

### 기본 이동 (hjkl 키)
```
        k (위)
        ↑
h ← 좌  |  우 → l
        ↓
        j (아래)
```

| 명령어 | 설명 | 단계 |
|--------|------|------|
| **h** | 왼쪽 이동 | 1글자 |
| **j** | 아래쪽 이동 | 1줄 |
| **k** | 위쪽 이동 | 1줄 |
| **l** | 오른쪽 이동 | 1글자 |

### 단어 단위 이동
| 명령어 | 설명 |
|--------|------|
| **w** | 다음 단어 시작으로 이동 |
| **b** | 이전 단어 시작으로 이동 |
| **e** | 단어 끝으로 이동 |

### 줄 내 이동
| 명령어 | 설명 |
|--------|------|
| **0** | 줄의 맨 앞으로 이동 |
| **$** | 줄의 맨 뒤로 이동 |
| **^** | 줄의 첫 문자로 이동 |

### 페이지 이동
| 명령어 | 설명 |
|--------|------|
| **Ctrl+f** | 한 페이지 앞으로 |
| **Ctrl+b** | 한 페이지 뒤로 |
| **G** | 파일 끝으로 |
| **gg** | 파일 시작으로 |
| **:123** | 123번 줄로 이동 |

## ✂️ 삭제 및 복사 명령어 (일반 모드)

### 삭제
| 명령어 | 설명 |
|--------|------|
| **x** | 커서 위치 문자 삭제 |
| **dd** | 현재 줄 전체 삭제 |
| **dw** | 현재 단어 삭제 |
| **d$** | 줄 끝까지 삭제 |
| **d0** | 줄 처음부터 삭제 |

### 복사 (Yank)
| 명령어 | 설명 |
|--------|------|
| **yy** | 현재 줄 복사 |
| **yw** | 단어 복사 |
| **y$** | 줄 끝까지 복사 |

### 붙여넣기
| 명령어 | 설명 |
|--------|------|
| **p** | 커서 다음에 붙여넣기 |
| **P** | 커서 이전에 붙여넣기 |

## 🔍 검색 및 치환

### 검색
```bash
# 아래쪽 검색
/검색어

# 위쪽 검색
?검색어

# 다음 검색 결과로
n

# 이전 검색 결과로
N
```

### 치환
```bash
# 현재 줄에서 첫 번째 발견 치환
:s/old/new/

# 현재 줄의 모든 발생 치환
:s/old/new/g

# 전체 파일 치환
:%s/old/new/g

# 확인 후 치환
:%s/old/new/gc
```

**예시:**
```
원본: hello world hello
:%s/hello/hi/g
결과: hi world hi
```

## 💾 파일 저장 및 종료

모두 **명령행 모드**에서 실행 (`:` 입력 후):

| 명령어 | 설명 |
|--------|------|
| **:w** | 저장 |
| **:w filename** | 다른 이름으로 저장 |
| **:q** | 종료 (저장 안 함) |
| **:wq** | 저장 후 종료 |
| **:q!** | 강제 종료 (변경 무시) |
| **:x** | 저장 후 종료 (:wq와 동일) |

## 🔧 Vim 특화 명령어 (vim에만 있음)

### Undo/Redo
```bash
u       # Undo (마지막 작업 취소)
Ctrl+R  # Redo (취소된 작업 복구)
```

### 분할 화면
```bash
:split          # 수평 분할
:vsplit         # 수직 분할
Ctrl+w + h/j/k/l  # 창 간 이동
```

### 완성 기능
```bash
Ctrl+p  # 이전 단어로 완성
Ctrl+n  # 다음 단어로 완성
```

## ⚠️ 자주 하는 실수

### 1. Insert 모드에서 나가기
```
문제: 텍스트가 자꾸 삭제됨
원인: Insert 모드가 아닌 일반 모드 상태
해결: Esc를 누르고 i를 눌러 Insert 모드 진입
```

### 2. 저장 안 하고 종료
```
문제: `:q`로 종료 시 에러
원인: 파일 변경 후 저장 안 함
해결: `:wq` 또는 `:q!` 사용
```

### 3. 실수로 내용 삭제
```
문제: 중요한 데이터 삭제됨
해결: `u` (Undo) 명령으로 복구
```
