Postman은 API 개발 및 테스트를 위한 협업 도구 및 플랫폼

### **API 테스트**

Postman은 API 엔드포인트에 대한 요청 및 응답을 테스트하기 위한 강력한 환경을 제공합니다. 사용자는 간단한 HTTP GET 요청부터 복잡한 RESTful API 및 GraphQL 요청까지 다양한 종류의 API를 테스트할 수 있습니다.

# 사용법

![[스크린샷_2023-10-04_오후_11.39.36.png]]

- 포스맨을 로그인 하고 나면 제일 초기의 화면
    - 많은 API 호출 때문에 많은 기록이 남아 있지만 사용해 본 적이 없다면 좌측의 기록과 상단의 카테고리는 없을 것임.

### 첫번째

- `**OverView**`** 라인에 있는 + 버튼을 눌러 항목을 추가 합니다.**

### 두번째

![[스크린샷_2023-10-04_오후_11.42.02.png]]

- 항목을 추가하면 이러한 초기의 화면이 보입니다.

### 세번째

![[스크린샷_2023-10-04_오후_11.42.11.png]]

- 우선 테스트할 API의 HTTP 메서드를 선택 합니다.
    - 우리는 POST 방식의 API가 대부분이니 POST 방식을 선택 합니다.

### 네번째

![[스크린샷_2023-10-04_오후_11.45.07.png]]

- POST 방식을 선택한 후 POST 옆의 INPUT에 테스트할 API 의 링크를 입력 합니다.
    - URL 및 엔드포인트 

### 다섯번째

![[스크린샷_2023-10-04_오후_11.45.27.png]]

- URL 밑의 카테고리 중 Body를 선택
    - 데이터 전송은 POST 방식으로 Body에 담아 보내기 때문
    [[데이터 전송 방식]]
- `**Body**`의 아래 항목에서 `**raw**`를 선택 하고 우측의 `**Text**`를 클릭해 `**JSON**` 형식의 데이터 포멧으로 변경 합니다.

### 마지막

![[스크린샷_2023-10-04_오후_11.45.58.png]]

- 서버로 보낼 데이터를 Body에 입력 합니다.
    - API 명세서에 존재하는  `**요청 sample**`** **을 담아 보내면 됩니다.
- 입력을 완료 했다면 우측 상단의 파란색의 버튼 Send를 클릭
- 하단의 서버의 응답 데이터 중 Body 에 정상적으로 데이터가 돌아 오는지 확인
    - 응답 데이터가 빈 데이터 거나 
    - 돌아와야 하는 예시 데이터와 틀린 경우
        - 서버 및 백엔드 쪽의 문제일 가능성이 있으니 백 엔드 관리자에게 문의.
