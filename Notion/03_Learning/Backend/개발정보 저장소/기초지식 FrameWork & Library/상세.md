# **프레임워크 (Framework)**

### **Angular (프론트엔드 프레임워크)**

- Angular는 Google에서 개발한 프론트엔드 프레임워크로, 대규모 웹 애플리케이션을 개발하기 위한 강력한 도구를 제공합니다.
- Angular는 애플리케이션의 전체 구조와 흐름을 정의하며, 개발자는 Angular 프레임워크에 따라 컴포넌트, 라우팅, 데이터 바인딩, 상태 관리 등을 구현합니다.

### **Spring (백엔드 프레임워크)**

- Spring은 Java 기반의 백엔드 프레임워크로, 엔터프라이즈급 웹 애플리케이션을 개발하는 데 사용됩니다.
- Spring은 애플리케이션의 구조와 규칙을 정의하며, 개발자는 Spring의 지침에 따라 컨트롤러, 서비스, 데이터 액세스 레이어 등을 구현합니다.

### **Express.js (백엔드 라이브러리)**

- Express.js는 Node.js를 위한 웹 애플리케이션 프레임워크로, 웹 서버 및 라우팅을 처리하는 기본 구조를 정의합니다.
- 개발자는 Express.js를 사용하여 HTTP 요청 및 응답을 처리하고 라우팅을 정의합니다.

# **라이브러리 (Library)**

### **React (프론트엔드 라이브러리)**

- React는 JavaScript 라이브러리로, 사용자 인터페이스(UI)를 구축하는 데 사용됩니다.
- React는 UI 컴포넌트를 만들고 관리하는 데 도움을 주며, 프로젝트의 구조나 흐름을 정의하지는 않습니다.

### **jQuery**

- jQuery는 라이브러리로, 웹 페이지에서 DOM 조작, 이벤트 처리, 애니메이션 등을 위한 함수와 메서드를 제공합니다.
- 개발자는 필요한 때 jQuery 함수를 사용하여 웹 페이지 상호작용을 개선할 수 있습니다. jQuery는 일종의 도구 상자처럼 사용됩니다.
- 개발자가 원하는 시점에 jQuery를 호출하고 사용하며, jQuery는 개발자의 명령에 따라 동작합니다.
