- **HTTP Connector**: HTTP 프로토콜을 사용하여 클라이언트와 통신하는 커넥터입니다. 클라이언트의 HTTP 요청을 수신하고, 이를 서블릿 컨테이너로 전달합니다.
- **HTTPS Connector**: HTTPS 프로토콜을 사용하여 보안된 통신을 제공하는 커넥터입니다. SSL(Secure Socket Layer) 또는 TLS(Transport Layer Security) 프로토콜을 사용하여 데이터 암호화를 지원합니다.
- **AJP Connector**: Apache JServ Protocol을 사용하여 웹 서버(Apache 등)와 통신하는 커넥터입니다. 웹 서버와 톰캣 간의 연동을 위해 사용됩니다.
