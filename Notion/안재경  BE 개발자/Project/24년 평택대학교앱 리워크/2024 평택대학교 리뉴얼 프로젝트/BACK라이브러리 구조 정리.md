## Lee

- 이 디렉토리는 프로젝트의 자바 소스 코드를 포함합니다.
- `**controller**`: 웹 요청을 처리하는 컨트롤러 클래스들이 위치합니다. 이 클래스들은 클라이언트의 요청을 받아서 비즈니스 로직을 호출하고, 응답을 반환합니다.
- `**service**`: 비즈니스 로직을 처리하는 서비스 클래스들이 위치합니다. 이 클래스들은 컨트롤러에서 요청받은 작업을 수행하고 데이터를 가공합니다.
- `**repository**`: 데이터베이스와 상호 작용을 하는 인터페이스 또는 클래스들이 위치합니다. 주로 데이터베이스 CRUD(Create, Read, Update, Delete) 관련 로직이 들어갑니다.
- `**model**`: 데이터 모델 클래스들이 위치합니다. 이 클래스들은 데이터베이스의 테이블과 매핑되어 비즈니스 로직에서 사용됩니다.

## resource

- 이 디렉토리는 자원 파일들을 포함합니다.
- `**static**`: 정적 리소스 파일들이 위치합니다. 예를 들어 CSS, JavaScript, 이미지 파일 등이 여기에 들어갑니다.
- `**templates**`: 템플릿 엔진 파일들이 위치합니다. 주로 Spring에서 사용하는 Thymeleaf 또는 Freemarker와 같은 템플릿 엔진을 위한 파일들이 들어갑니다.
- `**application.properties**`: 애플리케이션의 설정을 담은 파일입니다. 데이터베이스 연결 정보, 서버 포트 등을 설정할 수 있습니다.

## test

이 디렉토리에는 실제 테스트 코드가 위치합니다. 패키지 구조는 `**src/main/java**`와 유사하게 매칭되며, 해당 클래스들은 주로 애플리케이션의 서비스, 리포지터리, 컨트롤러 등과 관련된 단위 테스트 및 통합 테스트를 포함합니다.
