# ORM (Object-Relational Mapping)

ORM은 Object-Relational Mapping의 약자로, 객체 지향 프로그래밍 언어와 관계형 데이터베이스 간의 데이터를 변환하고 연결하는 프로그래밍 기술입니다.

간단히 말해서, ORM은 관계형 데이터베이스의 테이블을 객체 지향 프로그래밍 언어의 클래스로 매핑하여 데이터를 저장, 검색, 수정, 삭제할 수 있도록 해줍니다. 이를 통해 데이터베이스와의 상호 작용을 객체지향적으로 처리할 수 있습니다.

## 주요 기능

1. **객체와 테이블 매핑:** ORM은 객체 지향 프로그래밍 언어의 클래스와 관계형 데이터베이스의 테이블 간의 매핑을 제공합니다. 이를 통해 개발자는 데이터베이스 테이블을 객체로 생각하고 다룰 수 있습니다.
2. **데이터베이스 연산 처리:** ORM은 데이터베이스 연산을 객체의 메소드 호출로 처리할 수 있도록 지원합니다. 예를 들어, 객체의 메소드를 호출하여 데이터베이스에 새로운 레코드를 삽입하거나, 데이터를 수정하거나, 삭제할 수 있습니다.
3. **데이터 유효성 검사 및 관리:** ORM은 데이터베이스의 무결성을 유지하기 위해 데이터 유효성 검사를 지원합니다. 또한, 관련된 데이터를 캐시하여 성능을 향상시키는 등의 관리 기능도 제공합니다.
4. **SQL 생성 및 실행:** ORM은 객체와 데이터베이스 간의 매핑 정보를 바탕으로 필요한 SQL 쿼리를 자동으로 생성하고 실행합니다. 개발자는 SQL 쿼리를 직접 작성할 필요가 없으며, 대신 객체를 다루면 됩니다.
5. **관계 매핑:** ORM은 데이터베이스의 관계를 객체 간의 관계로 매핑할 수 있습니다. 예를 들어, 부모-자식 관계를 가지는 테이블 간의 관계를 객체 간의 상속 관계로 매핑할 수 있습니다.

ORM의 기능을 통해 개발자는 객체 지향적으로 데이터베이스와 상호 작용할 수 있습니다.

# 필요한 상황

### **복잡한 데이터베이스 작업**

 ORM은 복잡한 데이터베이스 작업을 단순화할 수 있습니다. 특히 다양한 조인이나 서브쿼리, 복잡한 필터링 조건 등을 포함하는 작업들은 ORM을 사용하여 더욱 간편하게 처리할 수 있습니다.

### **객체 간 관계 매핑**

 관계형 데이터베이스에서는 다양한 테이블 간의 관계가 존재합니다. ORM을 사용하면 이러한 관계를 객체 간의 관계로 매핑할 수 있습니다. 예를 들어, 부모-자식 관계를 가진 객체를 표현하거나, 다대다 관계를 해결하는 작업에 ORM을 사용할 수 있습니다.

### **객체 지향적인 데이터 처리**

 ORM을 사용하면 데이터베이스의 데이터를 객체 지향적으로 처리할 수 있습니다. 이는 개발자가 SQL 쿼리 대신 객체의 메서드를 호출하여 데이터를 조작하고 관리할 수 있음을 의미합니다.

### **데이터베이스와의 느슨한 결합**

 ORM을 사용하면 데이터베이스와 애플리케이션 간의 결합도를 줄일 수 있습니다. 데이터베이스 스키마의 변경이나 데이터베이스 시스템의 교체 등에 대응하기 쉽게 만들어줍니다.

### **반복 작업 최소화**

 ORM을 사용하면 반복적인 데이터베이스 작업을 최소화할 수 있습니다. 특히 CRUD(Create, Read, Update, Delete) 작업과 같은 일반적인 작업들을 자동화하여 개발자의 생산성을 향상시킵니다.
