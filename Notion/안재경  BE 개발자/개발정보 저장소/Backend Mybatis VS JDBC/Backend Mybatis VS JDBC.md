# **JDBC (Java Database Connectivity)**

- JDBC는 자바 프로그램에서 데이터베이스에 접속하고 SQL 쿼리를 실행하기 위한 자바 API입니다.
- JDBC를 사용하면 Java 애플리케이션에서 다양한 관계형 데이터베이스 시스템과 통신할 수 있습니다.
- JDBC의 핵심은 데이터베이스와의 연결, SQL 쿼리의 실행, 그 결과 처리 등을 위한 인터페이스와 클래스를 제공하는 것입니다.
- JDBC를 사용하면 개발자가 SQL 쿼리를 직접 작성하고 실행해야 하며, ResultSet을 통해 데이터를 처리해야 합니다.

# **MyBatis**

- MyBatis는 SQL 매핑 프레임워크로, **JDBC를 사용하여 데이터베이스와 상호 작용하는 애플리케이션을 보다 쉽게 개발할 수 있도록 도와줍니다.**
- MyBatis는 SQL 쿼리와 Java 객체 간의 매핑을 자동화하는 기능을 제공합니다. 이를 통해 개발자는 SQL 쿼리보다는 자바 객체를 조작하여 데이터베이스를 다룰 수 있습니다.
- MyBatis는 SQL 매핑 파일(XML 또는 어노테이션)을 사용하여 SQL 쿼리와 Java 메소드 간의 매핑을 정의합니다.
- MyBatis는** SQL 쿼리를 실행하고 결과를 자동으로 매핑**하여 Java 객체로 반환해주는 기능을 제공합니다. 또한 동적 SQL 쿼리를 작성하고 조작하는 기능도 제공합니다.

요약하자면, JDBC는 Java 애플리케이션과 데이터베이스 간의 저수준의 연결과 쿼리 실행을 담당하는 API이며, MyBatis는 JDBC를 활용하여 SQL 쿼리와 Java 객체 간의 매핑을 자동화하여 개발자가 보다 편리하게 데이터베이스와 상호 작용할 수 있도록 도와주는 프레임워크입니다.

# 선호되는 상황

## JDBC

1. **단순한 작업:** JDBC는 간단한 쿼리 및 CRUD(Create, Read, Update, Delete) 작업을 수행할 때 적합합니다. 예를 들어, 간단한 데이터베이스 조회나 갱신 작업 등이 해당됩니다.
2. **저수준의 제어 필요:** JDBC를 사용하면 데이터베이스 연결과 관련된 저수준의 작업을 직접 처리할 수 있습니다. 이는 개발자가 데이터베이스와의 연결 및 트랜잭션 관리를 직접 제어해야 할 때 유용합니다.
3. **SQL에 대한 완전한 제어 필요:** JDBC를 사용하면 개발자가 SQL 쿼리를 직접 작성하고 실행해야 합니다. 따라서 SQL에 대한 완전한 제어가 필요한 경우에는 JDBC를 선택할 수 있습니다.
    1. **완전한 제어 :** 개발자가 SQL 쿼리를 직접 작성하고 실행하는 것을 의미합니다. 이는 JDBC를 사용할 때 주로 발생합니다.

## **MyBatis**

4. **복잡한 SQL 작업:** MyBatis는 복잡한 SQL 쿼리를 다룰 때 특히 유용합니다. 매핑 파일을 사용하여 SQL 쿼리와 Java 메소드 간의 매핑을 정의하고, 동적 SQL을 작성하고 조작할 수 있습니다.
5. **ORM 기능 필요:** MyBatis는 ORM(Object-Relational Mapping) 기능을 제공하여 데이터베이스 테이블과 Java 객체 간의 매핑을 자동화합니다. 이를 통해 개발자는 SQL 쿼리보다는 Java 객체를 조작하여 데이터베이스를 다룰 수 있습니다.
6. **반복 작업 감소:** MyBatis는 미리 정의된 쿼리 및 프로시저의 사용을 지원하며, 이를 통해 반복적이고 일관된 코드 작성을 할 수 있습니다.

따라서 간단하고 직접적인 데이터베이스 작업이 필요한 경우에는 JDBC를 사용할 수 있으며, 복잡한 SQL 작업이나 ORM 기능이 필요한 경우에는 MyBatis를 사용하는 것이 유리합니다.
