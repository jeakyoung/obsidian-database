서블릿 컨테이너(Servlet Container)는 서블릿의 실행 환경을 제공하고 서블릿의 생명주기를 관리하는 런타임 환경입니다. 웹 서버와 웹 애플리케이션 사이에 위치하여, 클라이언트의 요청을 받아들이고 서블릿을 실행하여 요청을 처리합니다. 이를 통해 동적인 웹 애플리케이션을 구축하고 실행할 수 있습니다. 아래에서는 서블릿 컨테이너에 대해 자세히 설명하겠습니다.

### **주요 기능**

- **서블릿 실행**: 서블릿 컨테이너는 서블릿의 실행 환경을 제공하고, 서블릿을 메모리에 로드하여 실행합니다.
- **생명주기 관리**: 서블릿의 생명주기를 관리하며, 서블릿의 초기화(init), 요청 처리(service), 소멸(destroy) 등의 메서드를 호출합니다.
- **요청 및 응답 처리**: 클라이언트의 요청을 받아들이고, 해당 요청을 서블릿에 전달하여 처리하며, 서블릿이 생성한 응답을 클라이언트에게 반환합니다.
- **스레드 관리**: 각 요청마다 새로운 스레드를 생성하여 요청을 처리하고, 요청 처리가 완료되면 스레드를 반환하여 다음 요청을 처리합니다.
- **세션 관리**: 클라이언트와의 세션을 관리하고, 세션 정보를 유지합니다.
- **보안 및 인증**: 보안 기능을 제공하고, 인증과 권한 부여를 관리합니다.

### **주요 구성 요소**

- **웹 컨테이너(Web Container)**: 서블릿 컨테이너의 다른 용어로, 웹 서버와 웹 애플리케이션 사이에서 서블릿을 실행하고 관리하는 컴포넌트를 지칭합니다.
- **요청 및 응답 객체(Request and Response Objects)**: 클라이언트의 요청과 서버의 응답을 처리하기 위한 객체들입니다. 주로 HttpServletRequest와 HttpServletResponse 인터페이스를 사용합니다.
- **생명주기 리스너(Lifecycle Listeners)**: 서블릿의 생명주기 이벤트를 감지하고 처리하는 리스너입니다. 주요 이벤트로는 초기화(init), 소멸(destroy) 등이 있습니다.
- **세션 관리자(Session Manager)**: 클라이언트와의 세션을 관리하고, 세션 식별자를 부여합니다. 서블릿 컨테이너는 클라이언트에게 고유한 세션 ID를 부여하여 세션을 식별합니다.

### **주요 서블릿 컨테이너**

- **Apache Tomcat**: 가장 널리 사용되는 오픈 소스 서블릿 컨테이너이며, 아파치 재단에서 관리합니다.
- **Jetty**: 경량화된 서블릿 컨테이너로, Eclipse Foundation에서 관리합니다.
- **Undertow**: Red Hat에서 개발한 경량화된 서블릿 컨테이너입니다.

### **서블릿 컨테이너의 동작 과정**

1. 클라이언트의 요청이 웹 서버로 전송됩니다.
2. 웹 서버는 요청을 받아들이고, 서블릿 컨테이너에 해당 요청을 전달합니다.
3. 서블릿은 요청을 처리하고, 응답을 생성하여 서블릿 컨테이너에 반환합니다.
4. 서블릿 컨테이너는 생성된 응답을 클라이언트에게 전송합니다.
