
-> UX 개선 사항

## 0. 공통사항

ㅇ 입력 필드 포커스 점검하기.
ㅇ 해상도 별로 메뉴가 다 안보일 정도로 밀려 올라가는 경우가 생김 ( 기기가 작아질 경우에 문제는 없을지 점검 필요. ) -> 줄이든, 스크롤이 가능하게 하든 조치 방안 고민 필요
ㅇ 사이드바 클릭시 뒤로가기 동작 네비게이트가 안걸려있음 -> 앱이꺼지는 현상 방지 필요

## 1. 입고등록 조회부

ㅇ 구매 처 선택 시 바로 조회 될 수 있게

ㅇ 품목 명 입력 후 조회 시에 키보드 내려가게.

## 2. 입고등록

ㅇ 텍스트 입력시에 ( 사용자 포커스시에 ) 숫자필드에서 쉼표 안보이게

ㅇ 입고등록 이미지 촬영시 -> 사진 전체가 다 보일수 있게.

## 3. 입고수정시

ㅇ 입고일, 구매처, 품목명 오른쪽에 조회버튼은 의미가 없음 삭제하기

## 4. 라벨등록

ㅇ 구매처 라이크 검색 시 이상하게 나옴 ( 참조 위치가 잘못된듯! )

ㅇ 구매처 선택시 나오는 알러트를 서치박스 내에서 볼수있게 해주기 ( 클리어트리거도 안으로 )
