## 🔧 핵심 기술 개념

### Real-Time Database 아키텍처
- **특징:** 높은 동시성, 실시간 데이터 동기화
- **구현:** Spring + Reactive Libraries
- **최적화:** 트랜잭션 관리, 커넥션 풀
- **관련 문서:** 01_백엔드아키텍처 폴더

### N+1 Query 문제 해결
- **문제:** ORM 사용 시 불필요한 추가 쿼리 발생
- **원인:** Lazy Loading, 부정확한 조인
- **해결책:** Eager Loading, @Query with Join Fetch
- **관련 문서:** 02_데이터베이스최적화/[기술] N+1 문제

### Mybatis 동적 SQL
- **용도:** 동적 쿼리 생성 (조건에 따라 SQL 변경)
- **장점:** 유연성, 재사용성
- **주의:** SQL Injection 방지
- **관련 문서:** 02_데이터베이스최적화/[기술] Mybatis

### 인덱싱 전략
- **목표:** 쿼리 성능 최적화
- **방식:** 단일 인덱스, 복합 인덱스
- **주의:** 인덱스 유지보수 비용
- **관련 문서:** 02_데이터베이스최적화/[기술] 인덱싱
