# 📌 **테이블 정보**

---

## 🟦 **공통사항**

- DETAIL 페이지 → **항상 DETAIL 테이블 이전에 MAIN 테이블의 동일 키값 존재 必**
- **수주처** : 주문을 한 회사
- **발주처** : 외주작업이 필요해 주문을 넣는 회사
- **납품처** : 제품 제작 완료 후 재고를 보낼 회사
- **OEM** : 자재 관리
