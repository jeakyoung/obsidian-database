## 업무연락, 기안작성 요청사항

ㅇ 업무연락 부서용

→ 안쓸것같음 (간편하게 수정이 필요) 작성자체가 어렵다.

→ 작성시에 결재와 동시에 참조자에게 알림을 보내는 방식 (이미 구현된 기능)

→ 우측부에 확인시간이 리스트로 노출됨


→ 기안, 작성, 변경일을 주석처리해서 없에주세요 (수정하면 수정한날짜로 작성일을 변경)

→ 기안일만 보이도록 나머진싹다 hidden처리해주세요.

→ 출력물에 나오는 값대로 양식을 맞춰주세요.


ㅇ 외출/외근 계획정보 - 책임소재가 필요

→ 조회조건을 일단위로 조회할수 있게

→ 외근이 하나가 아닌 여러번 갈수가 있음. → 여러 줄이 추가될수 있는지 확인하기 // 가능하게 조치해주세요

→ 전체 조회 권한자를 만들어 주세요. → (방문처, 상담자, 목적, 출차, 업무종료) 기본값으로해주세요

→ 당일 기준으로 이전 날짜는 수정이 불가능하게 조치하기.

→ 관리자용 페이지를 하나 만들어서 조회할때 전체조회 가능하게 기존화면은 작성만 가능하게 (금요일까지)

행추가, 행삭제 버튼 / 조회는 기간으로 할수있게13


ㅇ 기준정보 기안 업무 구분

→ 분류 일반말고 전부 지우기 

→ 조치완료 → default 값을 일반으로 설정했음.

ㅇ 즐겨찾기 → 개별 세팅정보로 저장되는것

→ 공동 양식을 만들어주세요. ( 일단 공동양식으로 조치 ) → 사후조치는 알아서.
