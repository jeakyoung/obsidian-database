## 수정 내용

```javascript
{
                                            xtype: 'button',
                                            handler: 'WHR316_VW_btnClear',
                                            margin: '0 1 0 71',
                                            padding: '0 10',
                                            text: '조건 리셋',
                                        },
```

다음과 같이 전체 조건을 리셋 해주는 버튼을 선언합니다.

```javascript
WHR316_VW_btnClear: function (btn) {
        var me = this;

        var tf01 = me.getView().lookup('columns_tf01');
        if (tf01) tf01.setValue('');

        var tf02 = me.getView().lookup('columns_tf02');
        if (tf02) tf02.setValue('');

        var combo04 = me.getView().lookup('combo_04');
        if (combo04) combo04.setValue('');

        var combo06 = me.getView().lookup('combo_06');
        if (combo06) combo06.setValue('');

        me.onView();
    },
```

해당 버튼의 핸들러 선언입니다. 버튼 클릭시 그리드내 값을 가져오고 값이 존재할 경우 ‘ ‘ 빈 값으로

재설정 하여 조건을 삭제하는 동작을 구현했습니다.
