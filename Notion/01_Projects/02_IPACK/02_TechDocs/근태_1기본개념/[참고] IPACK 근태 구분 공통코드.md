## 📋 근태 코드 체계

### 정상 근무 (01~05, 16~18)

| 코드 | 항목 | 설명 |
|------|------|------|
| **01** | 기본일수 | 정상 근무 일수 |
| **02** | 기본시간 | 기본 근무 시간 |
| **03** | 잔업시간 | 정규 시간 후 연장 근무 시간 |
| **04** | 야근시간 | 야간 근무 시간 |
| **05** | 심야시간 | 심야 근무 시간 (자정 이후) |
| **16** | 출근 | 정상 출근 |
| **17** | 외출 | 근무 중 외출 |
| **18** | 주휴시간 | 주간 휴일 시간 |

| **07** | 연차사용 | 연차 휴가 | ✅ |
| **08** | 생휴사용 | 생리휴가 | ❌ 현재 빠져있음 |
| **19** | 유휴시간1 | 기타 휴가 유형 1 | ✅ |
| **20** | 지각체크 | 지각 상태 | ⚠️ 무휴일수로 되어있음 |

## 💡 사용 시 주의사항

### 현재 미구현 항목
- ❌ **06 월차사용:** 시스템에서 아직 미구현
- ❌ **08 생휴사용:** 시스템에서 아직 미구현

**필요 조치:** 해당 항목 구현 또는 대체 방안 마련

### 오류 항목

**필요 조치:** 데이터 정정 및 로직 수정 필요

## 📊 DB 저장 방식

### 테이블 구조 예상
```
근태코드 (CODE): 01 ~ 30
근태명 (NAME): 항목명
구분 (CATEGORY): 일수 | 시간 | 특수
활성여부 (ACTIVE): Y | N
```

### 샘플 데이터
```sql
INSERT INTO 근태코드 VALUES 
('01', '기본일수', '일수', 'Y'),
('02', '기본시간', '시간', 'Y'),
...
('13', '유특', '시간', 'N');  -- 삭제됨
```
