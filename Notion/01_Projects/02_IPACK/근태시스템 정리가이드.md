## 📋 분류 기준

### Category 1: 기본 개념 (2개)
**목적:** 근태 시스템의 기본 정보와 코드 정의

**포함 파일:**
1. ✅ IPACK 근태 구분 공통코드.md
   - 근태의 각 상태 정의 (정상, 지각, 결근 등)
   - DB 저장 코드

2. ✅ IPACK BioStar 근태기 코드 정보.md
   - BioStar 근태기로부터 수집되는 데이터
   - 코드 정의

**활용:** 신입 개발자, 시스템 이해 필요시

---

### Category 2: 기능 스펙 (4개+)
**목적:** 근태 기능의 상세 구현 스펙

**핵심 기능: WHR316 (주차별 근무조 등록)**

**포함 파일:**
1. ✅ iPACK주차별 근무조 등록 (WHR316) - 메인 기능
   - 화면 설명
   - 입력 항목
   - 동작 로직

2. ✅ 근태 년-월 버튼 만들기
   - 버튼 UI 구성
   - 이벤트 처리

3. ✅ 근태 주차 콤보 - 조회 - 등록 수정
   - 주차 선택 콤보박스
   - 조회 로직
   - 수정 로직

4. ✅ 기타 WHR316 관련 세부 기능들
   - 그리드 칼럼 정렬
   - 부서 검색 필터
   - 자동저장 기능 등

**활용:** 개발 시 구현 상세 참고

## 🎯 정리 실행 계획

### Phase 1: 폴더 생성 및 파일 분류
```bash
# 폴더 생성
mkdir 근태_1기본개념
mkdir 근태_2기능스펙
mkdir 근태_3현황관리
mkdir 근태_4유지보수

# 파일 이동 (각 카테고리로)
```

### Phase 2: 파일명 표준화
**변경 전:**
```
IPACK 근태 구분 공통코드.md
iPACK주차별 근무조 등록 (WHR316)/
```

**변경 후:**
```
[참고] IPACK 근태 구분 공통코드.md
[기술] WHR316 주차별 근무조 등록.md
```

### Phase 3: 메타데이터 추가
각 파일에 YAML 헤더 추가:
```yaml
---
type: 참고문서 | 기술문서
title: 명확한 제목
category: 근태기본 | 근태기능 | 근태현황 | 근태유지보수
date: YYYY-MM-DD
status: 완료 | 진행중 | 아카이브
---
```

### Phase 4: 인덱스 업데이트
- IPACK _INDEX.md의 근태 섹션 업데이트
- 각 카테고리별 설명 추가
