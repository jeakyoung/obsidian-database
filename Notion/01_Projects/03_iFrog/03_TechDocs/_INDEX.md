## 🔧 주요 기술 주제

### FCM (Firebase Cloud Messaging)
- **목적:** 실시간 푸시 알림 전송
- **적용 범위:** 주문 알림, 시스템 메시지
- **구현 방식:** Spring Boot + FCM SDK
- **관련 문서:** 01_FCM알림시스템 폴더

### Database Management
- **주요 구성:** MS SQL Server 또는 PostgreSQL
- **최적화 영역:** 
  - Connection Pooling
  - 쿼리 성능
  - 테이블 설계
- **관련 문서:** 02_데이터베이스 폴더

### Server Configuration
- **환경 분리:** DEV, TEST, PROD
- **설정 방식:** 환경변수 + 다형성
- **배포 프로세스:** 자동화된 서버 통합
- **관련 문서:** 03_서버환경 폴더
