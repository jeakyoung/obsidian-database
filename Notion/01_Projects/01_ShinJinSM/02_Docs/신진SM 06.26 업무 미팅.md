우리 MES
정남사업장 -> 000001
장수사업장 -> 000002
동탄사업장 -> 000003
직영사업장 -> 000004
천안사업장 -> 000005
남인천사업장 -> 000006
향남사업장 -> 000007
경기북부사업장 -> 000008
기획실 -> 000009
대전사업장 -> 000010
서울사업장 -> 000011
정남직영사업장 -> 000012


> WITH MES_MAPPING AS (
      SELECT '000001' AS MES_PLANT_CODE, '2000' AS CD_PLANT_매핑값, '정남'
  AS MES_사업장명 UNION ALL
      SELECT '000002',                   '1000',                    '장수'
                UNION ALL
      SELECT '000003',                   '3000',                    '동탄'
                UNION ALL
      SELECT '000004',                   '4000',                    '직영'
                UNION ALL
      SELECT '000005',                   '5000',                    '천안'
                UNION ALL
      SELECT '000006',                   '6000',                    '남인천'
                UNION ALL
      SELECT '000007',                   '7000',                    '향남'
                UNION ALL
      SELECT '000008',                   '8000',                    '경기북부'
                UNION ALL
      SELECT '000009',                   '9000',                    '기획실'
                UNION ALL
      SELECT '000010',                   '9100',                    '대전'
                UNION ALL
      SELECT '000011',                   '9200',                    '서울'
                UNION ALL
      SELECT '000012',                   '9300',                    '정남직영'
  )
  SELECT
      m.MES_PLANT_CODE,
      m.CD_PLANT_매핑값,
      m.MES_사업장명,
      p.CD_PLANT      AS DZ_CD_PLANT,
      p.NM_PLANT      AS DZ_공장명,
      CASE
          WHEN p.CD_PLANT IS NULL THEN 'Error'
          ELSE 'Success'
      END AS 검증결과
  FROM MES_MAPPING m
  LEFT JOIN NEOE.MA_PLANT p
      ON p.CD_COMPANY = '1000'
      AND p.CD_PLANT  = m.CD_PLANT_매핑값
  ORDER BY m.MES_PLANT_CODE

# **도면 가공** 

공정 이후 포장 시에 -> 도면 가공으로 넘기기

포장 일반 -> 출하로
도면 가공으로 추가해주고 포장 출하 시에 출하가 한 줄 더 생김


기존 일반 프로세스
수주 -> 공정 완료 -> 포장  -> 출하

도면 가공 프로세스 
수주 -> 공정 완료 -> 포장 ( 이력을 남길 때 "도면" 이라고 쌓기  ) -> 도면 가공 -> 포장  -> 출하


기존 출하 리스트에서 같이 조회하므로 반드시 포장 데이터랑 구분할 구분자를 추가하기 
( 네이밍 포장 사용 하지 않기 )




## 실적 등록 시 야간조 날짜 자동 계산

날짜를 지정하여 끝 자리 내 시간 범위가 24시 ~ 07시 30분 사이 일시 전날 기준으로 붙여주기가 필요함
-> 조치는 완료했으나 테스트 하지 않음 -> 날짜 전 처리 로직이 중복되어있는 부분이 존재하나
-> 기존에 정상 처리가 어떻게 가능했는지 파악이 안됨.














도면 가공 프로세스 
수주 -> 공정 완료 -> 포장 ( 이력을 남길 때 "도면" 이라고 쌓기  ) -> 도면 가공 -> 포장 ( 기존 
출하 리스트에 쌓기 "진짜" ) -> 출하
