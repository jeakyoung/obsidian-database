
## 도면 가공

외주 받은 자재로 바로 투입하는 경우도 있음, 비 규격 반은 길이 절단이 없음
입고에서 도면 가공을 찍으면 3400번으로 여기서 완료 시에 7000번으로

포장을 하든 하지 않든 -> 도면 가공에서 조회 가능해야 함

포장을 찍고 -> 도면 가공에서 조회

결론 : 일반 포장은 필수가 아님, 포장 = 생산 입고를 잡는다. / 완료 -> 3400 창고에서 
7000번으로 재고 이동.

1. 이전 실적 존재 시 : 3400 창고로 생산 실적 생성
2. 이전 실적 미 존재 시 : 
3. 3400번 창고로 실적이 있는 경우 포장 -> 출하 가능

도면 가공 창고를 만들고 -> 도면 가공 시에 창고 이동을 시키기. ( 생산 포장 )
완료 시에 -> 3400 창고로 창고 이동 생성

기본적으로 작업자들이 포장하면 안됨
근데 습관적으로 포장을 하는 경우를 고려해서 제작해야 함.

예외 사항 -> 

이전 공정이 아예 없는 경우
 창고에서 -1 됨.

도면 가공 들어가야 되는데 습관적으로 포장을 한 경우


## 정상 프로세스

측면/길이절단 (3000) -> 포장 완료 (창고이동) -> 도면시작 (6000) -> 도면완료 (3400) 
-> 포장 (7000)

-> 그냥 다 상관없음 이렇게 하면 됨

## 예외 사항

**플레이트 포장시 자동 스킵처리 (상관없음 어짜피스킵됨)**

**선행공정 실적이 없을때**

마이너스허용, 규격가져오기 (도면가공시에)
투입자재없이도 시작할수 있다.
