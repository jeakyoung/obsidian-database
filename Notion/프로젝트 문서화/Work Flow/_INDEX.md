## 🎯 정리 계획

### Phase 1: 폴더 구조 재정의
1. 프로젝트별 작업 폴더 생성
2. 서버 & 배포 폴더 생성
3. 기술 참고 폴더 생성
4. 관리 문서 정리

### Phase 2: 파일 분류 및 이동
- 프로젝트 기록 → 해당 프로젝트 Work Flow 폴더
- 서버/배포 → 서버 & 배포 폴더
- 기술 참고 → 기술 참고 폴더

### Phase 3: 메타데이터 추가
- 각 파일에 type, date, status 추가
- 표준 양식 적용

### Phase 4: 아카이빙
- 완료된 작업 아카이브 폴더로 이동

## 💡 사용 가이드

### 신규 작업 기록 추가 시
1. **파일 위치 선택:**
   - 특정 프로젝트 관련: [[프로젝트별 작업/_INDEX|프로젝트별 작업]]에서 해당 프로젝트 선택
   - 서버/배포 관련: [[서버 배포/_INDEX|서버 배포 문서]]
   - 일반 기술 참고: [[기술참고|기술 참고 가이드]]

2. **파일명 지정:**
   ```
   [YYYYMMDD] 작업 내용.md  (작업 기록)
   [기술] 내용.md           (참고 문서)
   ```

3. **메타데이터 추가:**
   ```yaml
   ---
   type: 작업기록
   title: [프로젝트] 작업 내용
   date: YYYY-MM-DD
   status: 진행중/완료
   ---
   ```
