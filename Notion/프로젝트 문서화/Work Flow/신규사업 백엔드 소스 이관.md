**[ReelTrip 체크리스트 페이지 개발 요청]**

전체 레이아웃: 3단 구성(좌측 사이드바 + 중앙 콘텐츠 + 우측 패널), 비율 약 2:5:3. 전체 배경 `#F5F6FA`.

상단 GNB: 좌측 로고(파란 원형 아이콘 + "ReelTrip" 텍스트, caption "박씨전님, 환영합니다"), 중앙 검색창, 우측 "시작하기" 파란색 버튼.

좌측 사이드바(너비 200px 고정, 흰색 배경): 메뉴 항목 — 🔵 대시보드 / ✈️ 여행계획 / 📅 캘린더(▼) / ☑️ 체크리스트(활성 상태, 파란색 배경 라운드, ▼) / 🚌 교통. 최하단: 원형 아바타 + "박지현" + "Pro 플랜".

중앙 콘텐츠: 상단 타이틀 "체크리스트" + 우측 "+ 항목 추가" 버튼. 카테고리 탭("전체 / 준비물 / 예약 / 할 일", 활성 탭 파란색 언더라인). 체크리스트 카드 그룹:

- 그룹 타이틀: "출발 전 준비" (접기/펼치기 ▼)
- 항목 리스트: 체크박스 + 항목명 + 담당자 아바타 + 마감일. 완료된 항목은 텍스트에 취소선 + 회색 처리.
- 그룹 타이틀: "현지 예약" (접기/펼치기 ▼)
- 항목 리스트 동일 구조.
하단 진행률 바: "전체 진행률 65%" + 파란색 프로그레스 바.

우측 패널(흰색 배경): 선택한 항목 상세. 항목명(대형 텍스트). 담당자(멤버 아바타 + 이름). 마감일("5월 14일"). 메모 입력창(textarea). 하단 "저장" 파란색 와이드 버튼.

디자인 스펙: 주색상 `#4A6CF7`, 전체 배경 `#F5F6FA`, 카드/사이드바 배경 `#FFFFFF`, 카드 border-radius 12px, 버튼 border-radius 24px, 폰트 Noto Sans KR.
