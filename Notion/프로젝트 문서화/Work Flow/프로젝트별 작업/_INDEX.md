## 💡 사용 가이드

### 새로운 작업 기록 추가 시
1. **해당 프로젝트 폴더 위치:** `프로젝트별 작업/[프로젝트명] 작업 기록/`
2. **파일명:** `[YYYYMMDD] 작업 내용.md`
3. **메타데이터:** 위 규칙에 따라 추가
4. **구조:** 작업 개요 → 상세 내용 → 해결 결과

### 프로젝트 폴더 없을 시
1. `프로젝트별 작업/[프로젝트명] 작업 기록/` 폴더 생성
2. `_README.md` 파일 추가 (선택)
3. 작업 파일 추가
