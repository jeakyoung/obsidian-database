# 문서 정기 관리 및 유지보수 체계

**목적:** 정기적인 문서 검토, 업데이트, 아카이빙으로 지속적인 품질 유지  
**담당:** 문서 관리자 (월 1회)  
**소요 시간:** 월 3시간  
**상태:** 운영 중  
**마지막 업데이트:** 2026-06-11

## 📅 월별 관리 일정

### 1주차: 메타데이터 검증 (30분)

#### 작업 항목
```bash
1. 신규 문서 확인
   - 지난달 추가된 문서 목록 작성
   - 메타데이터 완성도 확인 (type, status, date, category)
   
2. 메타데이터 일관성 검증
   - Status 값 정확성 (완료/진행중/보류)
   - Date 형식 통일 (YYYY-MM-DD)
   - Category 중복 없음 확인
   
3. 누락 항목 보완
   - 메타데이터 누락 문서 업데이트
   - 링크 유효성 검증
```

#### 체크리스트
```
□ 신규 문서 목록: ___개 추가
□ 메타데이터 완성도: __% 
□ 오류 항목: ___개 발견
□ 보완 완료: ✅
```

### 2주차: 인덱스 업데이트 (1시간)

#### _MAIN_INDEX.md 업데이트

```yaml
# 확인 항목
- 전체 프로젝트 상태 (진행률)
- 신규 추가 문서 목록
- 최근 변경 사항
- 우선순위 변경

# 업데이트 항목
- Phase별 완료도 업데이트
- 프로젝트별 통계 갱신
- 다음 단계 예정사항 반영
```

#### 프로젝트별 _INDEX.md 업데이트

```
각 프로젝트 인덱스:
├── 신진SM 프로젝트 DB/_INDEX.md
├── IPACK 프로젝트 DB/_INDEX.md
├── I-Frog 프로젝트 DB/_INDEX.md
├── NoNAME 프로젝트 DB/_INDEX.md
└── 기타 프로젝트...

확인 사항:
✓ 문서 개수 일치 여부
✓ 상태 정보 최신화
✓ 최근 업데이트 날짜
✓ 링크 유효성
```

#### Work Flow 폴더 인덱스 업데이트

```
Work Flow/_INDEX.md
├── 프로젝트별 작업/_INDEX.md
│   └── 9개 프로젝트 상태 확인
└── 서버 배포/_INDEX.md
    └── 기술 문서 현황 확인
```

## 📋 자동화 체크리스트

### GitHub Actions / CI/CD 연동

```yaml
# 신규 문서 자동 검증
name: Document Validation

on:
  pull_request:
    paths:
      - 'Notion/**/*.md'

jobs:
  validate:
    runs-on: ubuntu-latest
    steps:
      - name: Check Metadata
        run: |
          # 메타데이터 검증 스크립트
          python scripts/validate_metadata.py
      
      - name: Check Links
        run: |
          # 링크 유효성 검증
          python scripts/check_links.py
      
      - name: Check Format
        run: |
          # 포맷 일관성 검증
          python scripts/check_format.py
```

### 자동 리포트 생성

```bash
#!/bin/bash
# 월간 리포트 자동 생성 (매월 1일 09:00)

# 1. 신규 문서 통계
echo "=== 월간 문서 관리 리포트 ===" > report.md
echo "생성일: $(date)" >> report.md

# 2. 메타데이터 검증 결과
python scripts/analyze_metadata.py >> report.md

# 3. 링크 유효성 리포트
python scripts/analyze_links.py >> report.md

# 4. 아카이빙 대상 목록
python scripts/suggest_archiving.py >> report.md

# 5. 슬랙 알림
curl -X POST -H 'Content-type: application/json' \
  --data "{\"text\":\"월간 문서 리포트가 생성되었습니다: $(date +%Y-%m)\"}" \
  $SLACK_WEBHOOK_URL
```
