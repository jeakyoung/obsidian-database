# 포장 중복 문제 분석

## 문제 개요

신진SM ERP/MES 통합 시스템에서 출하 처리 중 **포장 중복(중복 데이터)** 문제 발생

---

## 문제 현황

### 증상
1. **발생 위치:** 제품창고 - 절단공정
2. **발생 조건:** 처리 중 타임아웃 → 롤백 → 동일 작업 재진행
3. **결과 현상:**
   - 같은 번호에 LOT만 다르게 나타남
   - 포장도 중복되어 수행됨
   - 특정 창고에 **마이너스(-) 재고** 발생

### 시스템 현황
```
MES:  타임아웃 → 롤백 ✓ (정상 작동)
      ↓
ERP:  타임아웃 → 롤백 ✗ (미작동)
      + 여전히 중복 데이터 반영
```

**API 응답 불일치:**
- MES: 작업 실패 응답
- ERP: 완료 성공 응답 (실제로는 미완료)

---

## 근본 원인 분석

### 가설 1: 트랜잭션 동기화 부재
**상황:** MES와 ERP가 독립적으로 작동하여 한쪽 롤백이 다른 쪽에 반영되지 않음

### 가설 2: 롤백 순서 오류
**상황:** ERP 커밋이 먼저 이루어진 후 MES 오류 발생

### 가설 3: 중복 체크 로직 미흡
**상황:** 이미 존재하는 데이터인지 확인 없이 새로 삽입

## 해결 방안

### 단계 1: ERP/MES 연동 함수 추가

더존 입고 조정 함수를 SP_WMA624_01_IUD 내에서 호출하도록 수정:

```java
// 더존 ERP와의 연동
private void syncToERP(String materialCode, String systemLotNo, float qty) throws Exception {
    Connection dzConn = getConnectionDZ(request, sc);
    try {
        // UP_PU_ITR_UPDATE 호출
        CallableStatement cstmt = dzConn.prepareCall("{call UP_PU_ITR_UPDATE(?, ?, ?)}");
        cstmt.setString(1, materialCode);
        cstmt.setString(2, systemLotNo);
        cstmt.setFloat(3, qty);
        cstmt.execute();
    } finally {
        dzConn.close();
    }
}

private Connection getConnectionDZ(ServletRequest request, ServletContext sc) throws Exception {
    Class.forName(sc.getInitParameter("driver")).newInstance();
    return DriverManager.getConnection(
        sc.getInitParameter("urlDZ"),
        sc.getInitParameter("usernameDZ"),
        sc.getInitParameter("passwordDZ")
    );
}
```

### 단계 4: 타임아웃 재시도 메커니즘

```java
public void executeWithRetry(int maxRetries, long timeoutMs) {
    int attempts = 0;
    while (attempts < maxRetries) {
        try {
            long startTime = System.currentTimeMillis();
            
            // 작업 실행
            executeStoredProcedure();
            syncToERP();
            
            long duration = System.currentTimeMillis() - startTime;
            if (duration > timeoutMs) {
                throw new TimeoutException("Processing timeout");
            }
            
            return; // 성공
        } catch (TimeoutException e) {
            attempts++;
            if (attempts >= maxRetries) {
                throw e;
            }
            Thread.sleep(1000 * attempts); // exponential backoff
        }
    }
}
```
