# 신진SM 05월 22일 - 중복 포장 문제

**회의 목적:** 포장 중복 발생 원인 분석 및 긴급 대응 방안 수립

---

## 주요 문제

### 중복 포장 발생 현황

**문제점:**
- 출하 처리 삭제 시 중복 문제 발생
- 같은 번호에 LOT만 다르게 나타나는 현상
- **심각성:** 중복에도 포장이 되면 특정 창고에서 **마이너스(-) 수량** 발생

**역사적 배경:**
- 이 작업 이전에도 간헐적 중복 데이터 발생
- 주로 오류 발생 시 나타남

**근본 원인 미파악:**
- [ ] 출하 처리 미완료가 원인인지?
- [ ] 시스템 오류인지?
- [ ] 데이터 동기화 미흡인지?

---

## 조치 상황

### 진행 중 작업
- 출하 처리 관련 로직 재검토 필요
- 로그 수집 및 분석

### 필요 조치
1. 중복 발생 타이밍 정확히 파악
2. MES/ERP 동기화 검증
3. 마이너스 수량 발생 메커니즘 규명
