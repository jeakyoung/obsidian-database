## 🛠️ 개발 환경 설정

### 1️⃣ 필수 도구 설치

#### Java Development Kit
```bash
# JDK 11 설치 확인
java -version
# 출력: openjdk version "11.0.x"

# JAVA_HOME 환경 변수 설정
export JAVA_HOME=/usr/lib/jvm/java-11-openjdk-amd64
export PATH=$JAVA_HOME/bin:$PATH
```

#### Maven 설정
```bash
# Maven 설치 확인
mvn -v
# 출력: Apache Maven 3.8.x

# settings.xml 설정
~/.m2/settings.xml
```

#### IDE 설정 (IntelliJ IDEA 권장)
```
File → Settings → Build, Execution, Deployment
  ├── Compiler
  │   └── Java Compiler: Target bytecode version = 11
  ├── Maven
  │   ├── Importing: Automatically download sources & javadoc
  │   └── Runner: Arguments: -DskipTests
  └── Inspections
      └── Severity: Errors only
```

#### 데이터베이스 설정
```bash
# PostgreSQL 설치 (개발용)
docker run --name noname-postgres \
  -e POSTGRES_PASSWORD= \
  -p 5432:5432 \
  -d postgres:14-alpine

# 데이터베이스 생성
psql -h localhost -U postgres
CREATE DATABASE noname_dev;
CREATE USER dev_user WITH PASSWORD '';
GRANT ALL PRIVILEGES ON DATABASE noname_dev TO dev_user;
```

#### Redis 설정 (캐싱용)
```bash
docker run --name noname-redis \
  -p 6379:6379 \
  -d redis:7-alpine
```

## 🔀 Git 협업 워크플로우

### 1️⃣ 브랜치 전략 (Git Flow)

```
main (운영 배포)
  ↑
release/v1.0 (릴리스)
  ↑
develop (통합 개발)
  ├─ feature/user-auth (기능 개발)
  ├─ feature/llm-integration (기능 개발)
  ├─ feature/db-optimization (기능 개발)
  ├─ bugfix/n+1-query (버그 수정)
  └─ hotfix/security-patch (긴급 수정)
```

### 2️⃣ 초기 설정

```bash
# 저장소 클론
git clone https://github.com/noname/noname-backend.git
cd noname-backend

# 개발 브랜치 체크아웃
git checkout -b develop origin/develop

# 또는 feature 브랜치 생성
git checkout -b feature/my-feature develop
```

### 3️⃣ 일상적 워크플로우

#### 새로운 기능 개발
```bash
# 1. 최신 develop 업데이트
git checkout develop
git pull origin develop

# 2. feature 브랜치 생성
git checkout -b feature/database-optimization

# 3. 개발 및 커밋
git add .
git commit -m "feat: Optimize N+1 queries in order service

- Add JOIN FETCH in order repository
- Implement batch query for product loading
- Performance improvement: 50% faster"

# 4. 푸시
git push origin feature/database-optimization

# 5. Pull Request 생성 (GitHub)
# base: develop ← compare: feature/database-optimization
```

#### 버그 수정
```bash
# bugfix 브랜치에서 작업
git checkout -b bugfix/incorrect-tax-calculation develop

git add .
git commit -m "fix: Correct tax calculation in invoice service

- Fixed tax rate calculation for different regions
- Closes #123"

git push origin bugfix/incorrect-tax-calculation
```
