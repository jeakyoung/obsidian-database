1.각 객체의 역활

Controller

→ 사용자 요청정보를 받아서 Biz에 전달하고 처리결과를 View에 전달한다. 


biz

→ UI에서 전달된 정보 또는 HTTPSession, ServletRequest를 파라미터로 받고 이정보를 바탕으로 비지니스 로직을 처리한다. 이때 DB에 C/R/U/D 작업이 필요한 경우 DAO 객체를 호출하여 처리한다.

DAO (Data Access Object)

→ 데이터베이스 관련 작업을 전달하는 객체이며 최종 처리는 biz에 위임시키고 처리결과만 전달한다.

→ 사용하는 이유 : 비지니스 로직이 매번 로드하고 객체를 생성하게 되면 너무 많은 커넥션이 일어나 DAO를 통해 DB전용객체로만 사용하여 부담을 줄이는 기술

DTO? VO?

데이터를 얻어 Service나 Controller로 보낼때 사용하는 객체

View(UI) ↔ Controller, biz ↔ DAO ↔ Database


util → 이건모징

sql → 데이터베이스 생성 및 조작언어
