- 프로젝트 이름 :  Open Soop
- **의도** :
    - 일반적 의도 :
        - 학과별로 개별 커뮤니티를 제작하여 학과내 소통창구를 만들기 위해
    - 개별화된 의도 :
        - 처음으로 시도하는 팀 개발 프로젝트로 개발 역량을 기르기 위해
        - 학회장 수행중 필요하다고 생각한 주제로서 실구현후 배포를 통한 사용자경험을 
       받아보고  싶어서.
- 구체적인 목표 :
    - 앱스토어 및 구글플레이 배포를 통한 사용자 경험 수집 및 오류 수정

- 기간 : 2023. 03 ~ 2023. 12

- 각 : 얼마만큼의 기간에, 특정 기능을 개발하는 것 - 혹은 프로젝트를 완료할 수 있을지에 대한 추측합니다. 프로젝트의 달성 가능성을 특정할 때 주요한 척도가 됩니다. 
    - 각이 보이지 않는 경우 : 
        - 각이 보일 때 까지 :
            1. 모호한 지점에 대한 학습 (Down - Top)
            2. MVP (Minimal Version Project) (Top - Down) 제작
            3. 자료 조사
        - 각이 아예 안 보이면, 해당 기능 등을 빼는 게 좋습니다.
    - 각이 보인 경우 :
        - 해당 기간에 따라 기간을 재설정
    - 한계에 대한 경계 : 물론, 이 각이 보이지 않는다 해도, 할 수 있습니다. 절대적인 규칙은 없음. 한계를 규정하지 마세요.
