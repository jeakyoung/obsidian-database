## 📋 개요

근무조별 일근태등록(WHR314)에서 시간 계산의 정확성을 높이기 위해 구현한 3가지 시간 변환 함수와 종합 계산 로직

---

## 🔧 핵심 개념

### 시간 계산의 3가지 반올림 규칙

#### 1️⃣ 지각/조퇴 (Minus Hour - ceil)
```
지각, 조퇴 같이 불리한 항목은 **올림 처리 (ceil)**

예시: 09:05 (9시간 5분)
→ 9시간 10분으로 올림 (더 불리하게)
→ 근무시간에서 더 많이 차감
```

**적용 항목:**
- LATE_TIME (지각시간)
- EARLY_TIME (조퇴시간)

#### 2️⃣ 초과근무 (Plus Hour - floor)
```
시간외 근무는 **내림 처리 (floor)**

예시: 20:50 (퇴근)
→ 20시간 40분으로 내림 (더 유리하게)
→ 초과근무 시간에서 더 적게 계산
```

**적용 항목:**
- OVER_TIME (초과근무)
- 특근 관련 계산

#### 3️⃣ 표준 시간 (Decimal Hour - round)
```
일반 근무시간은 **반올림 처리 (round)**

예시: 09:05 → 09:00 (반올림)
```

**적용 항목:**
- BASIC_TIME (기본근무)

## 💻 시간 변환 함수

### convertToMinusHour (지각/조퇴)

```javascript
convertToMinusHour: function (rawTime) {
    if (rawTime === null || rawTime === undefined || rawTime === '') return NaN;
    
    // HH:MM 형식 처리
    if (String(rawTime).indexOf(':') >= 0) {
        var parts = String(rawTime).split(':');
        if (parts.length >= 2) {
            var h = parseInt(parts[0], 10) || 0;
            var m = parseInt(parts[1], 10) || 0;
            var total = h + (Math.ceil(m / 10) * 10) / 60;
            return Number(total.toFixed(2));
        }
    }
    
    // HHMM 형식 처리
    var s = String(rawTime).replace(':', '');
    if (s.length === 3) s = '0' + s;  // 0905 → 09:05
    if (!/^\d+$/.test(s)) return NaN;
    
    var num = parseFloat(s) / 100.0;
    var hours = Math.floor(num);
    var minutes = Math.ceil((num - hours) * 100);  // 올림
    minutes = Math.ceil(minutes / 10) * 10;         // 10분 단위로 올림
    
    if (minutes === 60) {
        hours += 1;
        minutes = 0;
    }
    
    return Number((hours + minutes / 60).toFixed(2));
}
```

**처리 로직:**
1. NULL/빈값 확인
2. HH:MM 형식 → 시간 계산
3. HHMM 형식 → 0으로 패딩 후 계산
4. 분 단위를 10분 단위로 올림
5. 소수점 2자리 반환

**예시:**
```
입력: "0905" (09시간 5분)
→ 9 + ceil(5/10)*10/60
→ 9 + 10/60
→ 9.17 시간
→ 반환: "9.17"
```

**예시:**
```

→ 20 + floor(40/10)*10/60
→ 20 + 40/60
→ 20.67 시간
→ 반환: "20.67"
```

### convertToNightHour (야간근무)

```javascript
convertToNightHour: function (rawTime) {
    if (rawTime === null || rawTime === undefined || rawTime === '') return NaN;
    
    var s = String(rawTime).replace(':', '');
    if (s.length === 3) s = '0' + s;
    
    var num = parseFloat(s) / 100.0;
    var hours = Math.floor(num);
    var minutes = Math.floor((num - hours) * 100);
    minutes = Math.floor(minutes / 10) * 10;
    
    if (minutes === 60) {
        hours += 1;
        minutes = 0;
    }
    
    // 야간근무 = 24시간 기준
    return Number((hours + 24.0 + minutes / 60).toFixed(2));
}
```

**야간근무 계산 원리:**
```
예: 야간조 퇴근시간 22:00
convertToNightHour("2200")
→ 22 + 24.0 + 0/60
→ 46.0

다음날 06:00까지의 근무 계산에 사용
실제 근무시간: 22:00 ~ 06:00 (다음날) = 8시간
계산: 30.0 (다음날 06:00) - 22.0 (당일 22:00) = 8.0
```

## 🎯 주간조 vs 야간조 계산 차이

### 주간조 (WG_CODE == '001')
```
기본 근무시간: 09:00 ~ 18:00 (8시간)

기본근무 = 8.0 - 지각 - 조퇴
초과근무 = 퇴근시간 - 계획퇴근 - 0.5시간
야간 = 0 (주간조는 야간이 없음)
```

### 야간조 (WG_CODE == '002')
```
기본 근무시간: 22:00 ~ 06:00+1 (8시간)

기본근무 = 8.0 - 지각 - 조퇴 (야간 기준)
야간 = 7시간 (통상 7시간으로 계산)
야간수당 = 1시간
초과근무 = 퇴근시간 - 계획퇴근
```
