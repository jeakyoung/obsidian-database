## 🔧 주요 수정 사항

### 근무조별 일근태등록 (WHR314_VW) 개선
- **기본근무 적용:** 선택 시 기본 근무시간 자동 입력
- **시간 계산식:** 분단위 표와 일관화 처리
- **외출 조건:** KT_DATE 동일 날짜 조건으로 제한
- **시간 반올림:** ceil/floor 처리로 지각/조퇴/초과 시간 구분

### 증명서 발급 기능
- **주민번호 뒷자리:** 선택 가능하도록 수정
- **수정 파일:** SP_WHR103_01_RPT, WHR103_REPORT.java, WHR103_REPORT_*.jsp

### 부서 코드 동기화
- **문제:** DEPARTMENT_CODE 형식 불일치 (010072 vs 10072)
- **원인:** 개발/운영 환경 저장 방식 차이
- **해결:** 정상 등록 확인 완료
