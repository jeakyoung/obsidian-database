# ㅁ ERP

## ㅇ 기타입고등록

→ 단가, 금액, 부가세, 총액 → 세금 부여금액 자동설정

→ 품목내용을 많이 등록할 경우(수동입력)

→ 윗라인부터 저장이 되므로 저장을 눌렀을때 역순으로 저장됨 입고번호를 작은순서 보일수 있게

→ 항목을 추가할때 품의서 이름은 같이 추가됨

** 기타입고 등록에서 발주의뢰서 라는 형식에 맞게 출력 → 의뢰서 형식이 여러가지 존재함.

→ 수리, 제작, 연구, 금역 입력된 값 그대로 뒷쪽의 값들이 출력 되게만.

** 기타입고 현황에서도 규격옆에 품의서 이름 추가하기.

** 칼럼 행 → 순서 변경 하기 (드래그앤드롭X 순서 고정하는식으로)

## ㅇ 자재 마스터 등록

** 기본정보 → 대, 중, 소 분류 추가 → 원/부재료 분류 등록

## ㅇ 그룹웨어 → 기안서

기안서의 하위에 품의서가 존재함.

기준정보 → 기안업무구분에서 양식을 추가할수 있음

** 기안부서항목을 추가해주세요 / 간단하지 않음 부서가 항상 최신화됨 → 따로 별도추가해야함 데이터를 들고 있을 수 없음

** 기안서 작성 → 품의서 작성을 추가 / 기안서를 품의서로 변경

** 기계, 개발, 품질 부서마다 상이한 품의서 양식

** 년도 부서 개정 날짜 일련번호 → 해당 양식으로 통일된 품의서가 필요함

** 기존시스템 년월일 순번

**반품을 잡을때 (영업관리 → 기사별납품완료등록)

→ 반품사항 등록 부서에 영업부를 추가해주세요 (영업사고가 존재하기에)

→ 공통코드가 다름 (삭제된 항목도 전부 긁어옴.)

→ 삭제항목 ( 라벨, 코팅, 증착, 늄, 조립, 검사, 코팅(실) )

→ 부서내용에 영업부만 고정으로 추가하기 (해결방안)


** 거래명세표에서 단가, 공급가액 삭제하기

→ 단가를 단위로 바꾸고 공급가액을 박스수량으로. (해결방안)

→ 박스단위수량, 박스수량이 보일수있게 (출하계획현황)
