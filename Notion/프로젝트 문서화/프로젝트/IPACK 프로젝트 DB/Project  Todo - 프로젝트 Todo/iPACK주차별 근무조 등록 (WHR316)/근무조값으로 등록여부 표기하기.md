## 요청 사항

displayfield에 WG_FROM_DATE에 해당하는 그리드내 전체 데이터중 저장된 항목이 존재한다면 파란색으로

저장을 표기, 저장된 항목이 하나도 없다면 빨간색으로 미저장 표기 기능 개발

## 진행 사항

```javascript
{
                                            xtype: 'displayfield',
                                            itemId: 'WHR316_VW_RegGbn',
                                            margin: '0 0 0 92',
                                            height: 20,
                                            value: '<font color="red"></font>',
                                        },
```

RegGbn 이라는 displayfield를 선언했습니다. (WHR315_VW 참조)

```javascript
onView: function () {
        var me = this;

        var combo = me.getView().lookup('combo_01');
        var grid = me.getView().lookup('grid');
        var store = this.getViewModel().getStore('store_01');

        store.load({
            params: {
                FACTORY_CODE: combo.getValue() || '',
                WG_CODE: me.getView().lookup('combo_04').getValue() || '',
                JI_GROUP_CODE: me.getView().lookup('combo_02').getValue() || '',
                PAY_TYPE_CODE: me.getView().lookup('combo_03').getValue() || '',
                DEPT_CODE: me.getView().lookup('columns_tf01').getValue() || '',
                BASE_NAME: me.getView().lookup('columns_tf02').getValue() || '',
                WG_FROM_DATE: me.getView().lookup('combo_05').getValue() || '',
            },
            callback: function (records, op, success) {
                var counter = 0;
                if (success) {
                    Ext.each(records, function (rec) {
                        if (rec.get('WG_CODE')) {
                            counter++;
                        }
                    });
                    var RegGbn = me.getView().down('#WHR316_VW_RegGbn');
                    if (counter > 0) {
                        RegGbn.setValue('<font color="blue">저장완료</font>');
                    } else {
                        RegGbn.setValue('<font color="red">미저장</font>');
                    }
                }
            },
        });
    },
```

컨트롤러는 WG_CODE만 비교하도록 만들었습니다. view가 완료된 상황에 counter를 

임의 추가해서 onview 호출(주차콤보 선택시 마다) if문안에 WG_CODE를 가져와서 

값을 가져올수 있을때마다 counter에 값을 더합니다

이후 RegGbn에 counter가 동작한경우 (근무조 값이 하나라도 존재할떄) CSS값을 저장완료나 미저장으로

변경하여 displayField에 내려줍니다.
