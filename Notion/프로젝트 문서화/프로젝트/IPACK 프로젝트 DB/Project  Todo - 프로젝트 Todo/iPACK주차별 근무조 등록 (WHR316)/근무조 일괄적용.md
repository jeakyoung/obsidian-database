## 요청사항

UI: 근무조를 선택할 수 있는 콤보박스와 '적용' 버튼을 추가합니다.


기능: 콤보박스에서 특정 근무조(예: 주간조)를 선택 후 '적용' 버튼을 누르면, 화면에 조회된 모든 사원의 

근무조가 선택된 값으로 일괄 변경되어야 합니다.


유의사항: 화면에 표시되는 텍스트(주간조, 야간조)와 실제 DB에서 관리되는 코드 값 모두 변경되어야 합니다.

```javascript
WHR316_VW_btnReg: function (btn) {
        var me = this;

        var grid = me.getView().lookup('grid');
        var store = grid.getStore();
        var selected = me.getView().lookup('combo_06').getValue();
        var RegCheck = false;

        store.each(function (record) {
            if (record.get('SELECT_FLAG') === true) {
                RegCheck = true;
            }
        });

        if (!RegCheck) {
            showToast('알림', '적용할 대상을 선택해주세요.');
            return;
        }

        store.each(function (rec) {
            if (rec.get('SELECT_FLAG') === true) {
                rec.set('FACTORY_CODE', me.getView().lookup('combo_01').getValue());
                rec.set('WG_CODE', selected);
                rec.set('OPMAN_CODE', gUserId);
            }
        });

        store.sync({
            success: function () {
                showToast('알림', '일괄 적용을 완료하였습니다.');
                me.onView();
            },
        });
    },
```

CT 내부 일괄적용, 저장 로직 지정 그리드내 근무조 항목을 지정하고 SELECT_FLAG 값이 true ( 눌린경우)

에만 저장을 시행 선택된 부분 없이 저장 클릭시 alert메시지로 반환 이후 IUD에 필요한 값을 담고

WG_CODE값을 combo_06 (근무조 일괄적용내 선택된 데이터)로 담아 store.sync(저장) 재조회
