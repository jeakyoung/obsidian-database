## 개발 내용

```sql
,  @YYYYMM				VARCHAR(14)
,  @WG_FROM_DATE		VARCHAR(8)

WHERE LEFT(WG_FROM_DATE, 6) = @YYYYMM
			AND WG_FROM_DATE = @WG_FROM_DATE
```

해당 부분을 LIST 프로시저에 추가하여 년 월이 일치하는 것과 주차 시작일이 정확히 같은것만 select 하도록

```javascript
uLMonthPrevious: function () {
        var me = this;
        var strDate;

        var nYymm = me.getView().down('#WHR316_VW_yymm').getValue();

        strDate = nYymm.substr(0, 4) + '-' + nYymm.substr(5, 2) + '-' + '01';
        var nDate = new Date(strDate);
        nDate = Ext.Date.add(nDate, Ext.Date.MONTH, -1);

        var mm = (nDate.getMonth() + 1).toString(); //January is 0!
        var yyyy = nDate.getFullYear().toString();
        mm = mm[1] ? mm : '0' + mm[0];

        me.getView()
            .down('#WHR316_VW_yymm')
            .setValue(yyyy + '-' + mm);

        me.onSetCombo_05(yyyy + mm);

        this.onView();
    },
```

월 변경을 위한 버튼의 가장아래쪽에 OnSetCombo_05를 추가하여 월 변경 동작시 Combo를 재로드

하여 변경된 월에 알맞은 콤보 주차정보를 제공하도록 구현했습니다.
