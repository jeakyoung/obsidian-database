```javascript
WHR316_VW_btnCng: function (btn) {
        var me = this;
        var grid = me.getView().lookup('grid');
        var store = grid.getStore();
        var RegCheck = false;

        store.each(function (record) {
            if (record.get('SELECT_FLAG') === true) {
                RegCheck = true;
            }
        });

        if (!RegCheck) {
            showToast('알림', '변환할 대상을 선택해주세요.');
            return;
        }

        store.each(function (rec) {
            var wgCode = rec.get('WG_CODE');

                rec.set('FACTORY_CODE', me.getView().lookup('combo_01').getValue());
                rec.set('OPMAN_CODE', gUserId);
                rec.set('WG_FROM_DATE', me.getView().lookup('combo_05').getValue());
                if (wgCode === '001') {

                    rec.set('WG_CODE', '001');
                }
            }
        });
```

rec에 변환내용을 적재해줍니다.

```javascript
onReg: function () {
        var me = this;

        var grid = me.getView().down('grid');
        var store = grid.getStore();

        var modifiedRecords = store.getModifiedRecords(); //수정여부 확인
        var removedRecords = store.getRemovedRecords(); //삭제여부 확인
        if (modifiedRecords.length == 0 && removedRecords.length == 0) {
            Ext.Msg.alert('알림', '변경된 내역이 없습니다.');
            return;
        }

        for (var i = 0; i < store.getCount(); i++) {
            var rec = store.getAt(i);
            if (rec.get('WG_CODE')) {
                // if (rec.dirty) {
                rec.set('FACTORY_CODE', me.getView().lookup('combo_01').getValue());
                rec.set('OPMAN_CODE', gUserId);
                rec.set('WG_FROM_DATE', me.getView().lookup('combo_05').getValue());
                // }
            } else {
                rec.set('SELECT_FLAG', false);
                continue;
            }
        }

        store.sync({
            success: function () {
                showToast('알림', '저장 하였습니다.');
            },
            callback: function () {
                me.onView();
            },
        });
    },
```

이후 onReg에서 IU과정의 필수조건인 WG_CODE가 존재하는 경우에만 rec의 변경사항이 있는것들에 한해

필수정보를 같이 실어주고 만약 근무 조 데이터가 존재하지 않는다면 SELECT_FLAG를 뽑아서 변경사항이

없는것으로 만들어 줍니다.
