## 요청사항

UI: '근무조 변환' 버튼을 추가합니다.


기능: 버튼을 클릭하면 화면에 조회된 모든 사원의 근무조가 현재 설정된 조의
반대 조로 자동 변환됩니다. (예: 주간조 → 야간조 / 야간조 → 주간조)


유의사항: 이 기능 역시 화면의 텍스트와 실제 관리되는 코드 값 모두 함께 변환
되어야 합니다.

## 진행사항

![[image 136.png]]

WG_CODE 호출부 TIN310 테이블 확인시 Combo의 구분자 WG_CODE 값이 주간은 001, 야간은 002로 되어

있습니다. 변환 버튼 클릭시 이 둘의 값이 TIN312내에서 실제로 변경되어야 합니다.

```javascript
{
                     xtype: 'button',
                     handler: 'WHR316_VW_btnCng',
                     margin: '0 1 0 10',
                     padding: '0 5',
                     text: '근무조 변환',
 },
```

일괄 적용과 마찬가지로 버튼을 선언하고 handler를 선언해 해당부 클릭시 발생하는 이벤트를 controller

에서 처리하는 방식으로 구현했습니다.

```javascript
WHR316_VW_btnCng: function (btn) {
        var me = this;
        var grid = me.getView().lookup('grid');
        var store = grid.getStore();
        var RegCheck = false;

        store.each(function (rec) {
            var wgCode = rec.get('WG_CODE');

            rec.set('FACTORY_CODE', me.getView().lookup('combo_01').getValue());
            rec.set('OPMAN_CODE', gUserId);

            if (wgCode === '001') {
                rec.set('WG_CODE', '002');
                RegCheck = true;
            } else if (wgCode === '002') {
                rec.set('WG_CODE', '001');
                RegCheck = true;
            }
        });

        if (!RegCheck) {
            showToast('알림', '주간, 야간만 변환 가능합니다.');
            return;
        }

        store.sync({
            success: function () {
                showToast('알림', '근무조를 변환하였습니다.');
                me.onView();
            },
        });
    },
```

grid 내 WG_CODE를 가져와서 FACTORY_CODE와 OPMAN_CODE를 미리 등록해 줍니다 (NULL값 방지)

만약 가져온 WG_CODE가 ‘001’ → 주간 이라면 ‘002’ 야간으로 변경, WG_CODE가 ‘002’ → 야간이라면

반대로 ‘001’ 주간으로 변경 해당하는 사항에 없는 사무실, 새벽조의 경우 조건을 만족하지 않기에 값이

변경되지 않습니다. 이후 SYNC를 통해 근무조 변환사실을 알립니다.
