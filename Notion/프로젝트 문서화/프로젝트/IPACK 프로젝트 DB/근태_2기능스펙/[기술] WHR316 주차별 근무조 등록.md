# WHR316 주차별 근무조 등록 기능 상세 스펙

**폼번호:** WHR316  
**기능명:** 주차별 근무조 등록  
**개발 기간:** 2025-09-08 ~ 2025-09-16  
**상태:** 완료 ✅  
**담당자:** 안재경

---

## 📋 기능 개요

선택된 월의 주차별로 근무조를 개별 등록할 수 있는 기능

**핵심 특징:**
- 월단위 선택 (근태 년-월)
- 주차단위 조회
- 근무조 일괄 적용/변환
- 실시간 저장 및 조회

### Phase 2: 일괄 적용/변환 기능 추가 (09.09 ~ 09.10)

**작업 내용:** 조회된 데이터 전체의 근무조를 한 번에 변경할 수 있는 기능 추가

**구현 항목:**
1. **근무조 일괄적용**
   - 선택된 근무조를 모든 행에 적용
   - 버튼: "일괄 적용"

2. **근무조 변환**
   - 기존 근무조를 다른 근무조로 변환
   - 버튼: "근무조 변환"

**관련 문서:**
```
[[근무조 일괄적용]]
[[근무조 변환]]
```

---

### Phase 3: 조회 조건 필드 추가 (09.10 ~ 09.11)

**작업 내용:** 조회 조건에 시간 관련 필터 추가

**추가 필드:**
- **근태 년-월:** 조회 대상 년월 선택
  - 버튼 형식
  - 달력 선택 가능

- **근태 주차:** 조회 대상 주차 선택
  - 드롭다운(콤보박스)
  - 주차 자동 계산

**구현 세부:**
1. **근태 년-월 버튼**
   - UI: 버튼 형식 ([◀ 2025년 9월 ▶])
   - 달력 팝업으로 년월 선택
   - 선택 시 자동으로 주차 콤보 업데이트

2. **근태 주차 콤보**
   - 선택된 월의 주차 자동 계산
   - 드롭다운: [주차1], [주차2], [주차3], [주차4], [주차5]
   - 조회/등록/수정 조건으로 사용

**관련 문서:**
```
[[근태 년-월 버튼 만들기]]
[[근태 주차 콤보 - 조회 - 등록 수정]]
  ├─ 1. 주차 계산 콤보 버튼 만들기
  ├─ 2. 주차에 따른 IUD 수정
  └─ 3. 주차에 따른 조회 조건 변경
```

## 💡 주요 기술 사항

### DB 테이블
- **근태 년월 테이블:** 선택된 년월 저장
- **주차 계산 로직:** 년월에서 주차 자동 계산
- **근무조 데이터:** 주차별 근무조 정보

### 조회 로직
```
1. 근태 년-월 선택
   ↓
2. 주차 자동 계산 및 콤보 업데이트
   ↓
3. 조회 조건 적용
   ↓
4. 그리드 데이터 로드
   ↓
5. 근무조 표시
```

### 저장 로직
```
1. 근무조 선택/변경
   ↓
2. 저장 버튼 클릭
   ↓
3. 유효성 검사 (주차 선택 확인)
   ↓
4. DB 저장 (IUD)
   ↓
5. 그리드 업데이트
```
